第一部分：LINE 帳號安全

為什麼要先做這件事

等一下你的個人 LINE 會綁成保客+ 的「業務工作台」，打開就看得到你所有客戶與保單。 個人 LINE 被盜，等於客戶名單被盜；官方帳號被盜，對方可以用你的名義傳訊息給客戶。

LINE 安全檢查清單（當場打勾）

選單名稱可能因 LINE 版本略有不同，找不到請舉手問助教。

個人 LINE

  • 密碼：已設定、夠長、沒有跟其他網站共用（設定 → 我的帳號）
  • Email：已綁定，而且收得到信（設定 → 我的帳號）
  • 電話號碼：正確、收得到簡訊
  • Apple 或 Google 帳號：已綁定（被盜時比較有機會找回原帳號）
  • 允許自其他裝置登入：平常關閉，要用電腦版時再打開（設定 → 我的帳號）
  • 登入中的裝置：看過一遍，沒有不認得的裝置（設定 → 我的帳號 → 登入中的裝置）
  • 電腦版、iPad：用 QR Code 登入；不在公用電腦登入；有開 Face ID／指紋的話，可關閉密碼登入
  • Letter Sealing（訊息加密）：保持開啟（設定 → 隱私設定）
  • 加好友：關閉「自動加入好友」「允許被加入好友」；可開「阻擋訊息」
  • 電信語音信箱：用不到就關閉，或改掉預設密碼

LINE 官方帳號（Business ID）

  • Business ID 已開二階段驗證，備用碼存在安全的地方
  • 官方帳號後台「設定 → 權限管理」：只有自己是管理員；助理、小編是操作人員
  • 沒有已離職、不認識的成員
  • LINE Developers Console 的 Provider 成員也看過一遍（那裡拿得到金鑰）

四句一定要記住

  1. 簡訊驗證碼絕不給任何人，包括自稱 LINE 客服、朋友、投票活動。LINE 的任何登入網頁都不會要你輸入簡訊驗證碼。
  2. 不點陌生短網址，尤其是「登入領好康」「綁定 Apple／Google 帳號」的頁面。
  3. 官方帳號從可信的地方加：公司官網、名片上的 QR Code；不從陌生訊息加。
  4. 金鑰（Channel Secret、Access Token）跟密碼一樣，不拍照、不傳群組，貼完就刪。

被盜了怎麼辦（照順序做）

個人 LINE 被盜

  1. 還能登入：立刻改密碼 → 登出不認得的裝置 → 關閉「允許自其他裝置登入」。
  2. 不能登入：到 LINE 客服問題回報表單，登入頁選「不登入並繼續操作」，類別選帳號被盜用，本人填寫。
  3. 用電話、簡訊或其他管道通知好友與客戶：「這段時間收到我要錢、要點數、傳連結的訊息都不是我。」
  4. 保客+ 這邊（見下面）。

官方帳號被盜

  1. 還進得去：移除可疑成員 → 改 Business ID 密碼 → 確認二階段驗證 → 檢查群發紀錄、自動回應、圖文選單有沒有被改。
  2. 進不去：聯絡 LINE 官方帳號客服，必要時請 LINE 先停用帳號。
  3. 到 LINE Developers Console 重新發行 Channel Access Token（舊的立刻失效）、Channel Secret 也重新發行；檢查 Webhook 網址有沒有被改。
  4. 回保客+ 後台「系統設定 → LINE 串接 → LINE 參數」，貼上新的 Access Token（與新的 Secret），按「儲存並驗證」，再按「測試連線」看到自己的官方帳號名稱才算完成。沒換的欄位留空即可，留空代表不變更。

保客+ 這邊（個人 LINE 被盜或換手機時）

  1. 後台「保險業務 → 團隊與業績 → 組織與業務」（頁名「我的業務資料」）按「產生綁定連結」，用新的 LINE 打開按「確認綁定」，舊的綁定會自動解除。
  2. 工作台「行事曆 → 同步到手機行事曆」重新產生網址，舊網址立刻失效。
  3. 後台登入密碼一起換。

第二部分：保客+ 是什麼

保客+ 是給保險業務的客戶經營系統。你今天拿到的是個人版：你自己就是管理者也是業務，官方帳號、好友、訊息費用都屬於你自己。

你的一天

時間 你在做什麼 在哪裡
07:30 收到一則早報：今日行程、今天先處理這幾位、到期提醒、待確認祝福、久未聯絡 自己的 LINE
早上 逐則看祝福草稿、按確認，09:00 從你的官方帳號送出 工作台「祝福」
拜訪中 打開家庭保障總表跟客戶談 工作台「我的家庭」
拜訪後 記一筆拜訪與下次行動 工作台「活動量」或家庭明細
隨時 客戶問「下次什麼時候繳費」，系統依保單自動回答；理賠問題轉給你 工作台「客戶訊息」
晚上 對助理說「記：王小明想了解退休規劃」，確認後存成筆記 官方帳號聊天室

三條底線

  • 不收健康資料。
  • AI 只出草稿，你確認才生效。
  • 對外訊息自動附你的姓名與所屬機構。

第三部分：現場串接（你自己的後台＋你自己的 LINE 後台）

開始前請準備

  • 我們發的後台網址、帳號、密碼
  • LINE 官方帳號的 Messaging API：Channel ID、Channel Secret、Channel Access Token（長期）
  • LINE Login channel：Channel ID、Channel Secret（LIFF ID 不用準備，系統會自動建立）
  • 能登入 LINE Developers Console 與官方帳號後台的電腦或手機
  • 你的夥伴（坐隔壁的同學），等一下互相當「測試客戶」

第一站：Messaging API 與 Webhook

  1. 登入自己的後台。
  2. 進「系統設定 → LINE 串接 → LINE 參數」。
  3. 在「Messaging API Channel」貼上 Channel ID、Channel Secret、Channel Access Token（長期）。
  4. 按「儲存並驗證」，看到綠色「已驗證」和你的官方帳號名稱。
  5. 不用自己貼 Webhook 網址。儲存成功後，系統會自動把 Webhook 設好，並請 LINE 送一次測試，結果顯示在卡片下方：
    • 綠燈「Webhook 已自動設定完成」：完成，不用動。
    • 黃燈「Use webhook 開關目前是關閉的」：到 LINE Developers Console → 你的 Messaging API channel → Messaging API 分頁，自己把「Use webhook」打開（LINE 規定這個開關只能本人點），再回後台按「檢查 Webhook」，直到綠燈。
  6. 到官方帳號後台「回應設定」，關閉自動回應訊息。

第二站：LINE Login 與自動建立 LIFF

  1. 同一頁往下「LINE Login Channel 與 LIFF」，貼上 LINE Login Channel ID、Channel Secret，按「儲存」。LIFF ID 不用貼。
  2. 按「自動建立／校正 LIFF」。系統會幫你建好 LIFF（Size＝Full、三個 Scopes、加好友選項、Endpoint 網址都設好），並把 LIFF ID 自動存回去。畫面會列出還要你手動做的項目。
  3. 這三件事 LINE 不開放系統代做，要自己到 LINE Developers Console 做：
    • LIFF 分頁：打開 shareTargetPicker。
    • LINE Login channel → Basic settings：把 Linked LINE Official Account 選成你自己的官方帳號。連結好之後，如果畫面提示加好友選項被先設成關閉，再按一次「自動建立／校正 LIFF」。
    • 複製畫面上的「Callback URL」，貼到 LINE Login 設定。結尾的斜線不能少。
    • 順便確認 channel 的 Region 是 Taiwan（建立時選的，建好不能改）。
  4. LINE Login channel 狀態改成「已發布（Published）」。這一步最常漏，而且你自己測不出來，等一下要用夥伴的手機驗。

（上線後補截圖：自動建立 LIFF 的結果清單）

第三站：首次設定、綁定工作台、同 Provider 檢查、加好友

  1. 後台「保險業務 → 團隊與業績 → 組織與業務」（頁名「我的業務資料」）：
    • 選職業別（保險業務員／銀行理專／獨立理財顧問）
    • 填本人資料：姓名、手機、所屬機構、登錄字號（選填）
    • 資料控制者：預設是你的姓名與手機（個人版的資料控制者是你本人）
    • 逐項勾選開通確認
    • 按「完成設定」
    • 這一步一定要你本人登入勾選，我們不能代勾。
  2. 畫面出現「綁定連結」，傳到自己的 LINE，在手機打開，按「確認綁定」。連結 72 小時內有效、只能用一次。
  3. 用自己的 LINE 加自己的官方帳號為好友（不加好友收不到早報）。
  4. 同一個 Provider 檢查（要用夥伴的手機，夥伴不是你這個 LINE Developers 的管理員，才測得出 Published）：
    1. 你在「LINE 參數」頁最下方按「開始檢查」（15 分鐘內有效）。
    2. 夥伴用他的 LINE 加你的官方帳號為好友。
    3. 夥伴用同一支手機打開卡片上顯示的 LIFF 網址，登入。如果手機出現 400 錯誤，代表 Login channel 還沒發布，回第二站第 4 步。
    4. 你回後台按「查看結果」：綠色「通過」＝兩個 channel 在同一個 Provider，而且已發布；紅色「查不到」（確定夥伴已加好友）＝不在同一個 Provider，找助教；黃色「還沒收到 LIFF 登入」＝夥伴手機還沒登入完成。
    5. 換你的手機，幫夥伴也檢查一次。
  5. 請夥伴傳一句「測試」。你在後台「訊息發送 → 會員留言」看得到，就代表接通了。

串接完成清單

  • Messaging API 顯示「已驗證」
  • Webhook 燈號綠色（Use webhook 已自己打開）
  • 自動回應訊息已關
  • LINE Login 已儲存、LIFF 已自動建立，shareTargetPicker、連結官方帳號、Callback URL 已手動設好，Login channel 已發布
  • 首次設定已完成
  • 自己的 LINE 已綁定工作台、是自己官方帳號的好友
  • 夥伴已加你的官方帳號、同 Provider 檢查綠燈、傳的訊息看得到

沒準備好金鑰怎麼辦

  • 還沒有官方帳號：今天先不要現場申請（Provider 選了不能換，匆忙選錯會很麻煩）。先在後台練習建客戶與保單（沒接 LINE 也能用後台），LINE 的部分跟夥伴一起看。課後我們陪你申請。
  • 有官方帳號、沒開 Messaging API：到補救站，助教陪你從官方帳號後台啟用。
  • 沒有 Login channel：先完成第一站與首次設定，Login channel 到補救站建。Login channel 一定要和 Messaging API 在同一個 Provider 底下；建好後貼兩項，LIFF 仍按「自動建立」即可。
  • 先做完的人：拿「提早完成練習卡」先往下做，或幫隔壁同學對照步驟（不碰別人的金鑰）。

第四部分：功能操作

業務工作台底部：今天、我的家庭、客戶訊息、行事曆、我。「今天」頁下方有捷徑：祝福、經營、提醒、活動量、關懷訊息、AI 助理。

1. 客戶與家庭

步驟

  1. 工作台「我的家庭」→ 建家庭。
  2. 新增成員：姓名、性別、生日、手機、職業類別、年收入級距、備註。
  3. 勾「已向當事人說明告知事項並取得同意」，選取得方式（書面、口頭、LINE 對話）。
  4. 設定家庭關係（配偶、子女、父母、兄弟姊妹、其他）與分級 A～D。

記住

  • 沒有 LINE 的小孩、長輩也要建成成員。
  • 沒勾同意不能儲存。未成年子女、長輩可由同戶家人代為同意。
  • 年收入級距會影響保障缺口的壽險建議；沒填會顯示「無法判斷」。
  • 分級決定多久沒聯絡會提醒（預設 A 30 天、B 60 天、C 90 天、D 不提醒）。
  • 備註打到疾病字詞會跳提醒，請刪掉。

2. 保單與家庭保障總表

手動登錄步驟

  1. 家庭頁點「保單」→ 新增。
  2. 填保險公司、商品名稱、保單號碼、要保人、被保險人、生效日、滿期日、繳別、繳費年期、保費、幣別、繳費方式、狀態。
  3. 加保障明細：主約、附約、保額（醫療記住院日額）。

拍照讀保單步驟

  1. 按「拍照讀取保單首頁」，只拍保單首頁，不要拍健康告知書。
  2. 系統讀成草稿，每欄標示「已讀取／請核對／看不清楚未填入」。
  3. 逐欄對照保單核對、補上沒填的。
  4. 按「確認儲存」才會建立。
  • 一次最多 6 張（首頁、附約明細、保險存摺截圖、繳費通知單）。
  • 偵測到健康告知頁會整張丟棄。
  • 每月有使用上限，用完就手動登錄。

記住

  • 保障明細才是保障總表的計算依據，沒填明細的保單只會出現在清單裡。
  • 繳費方式只記類別，不記卡號帳號。
  • 保障總表每位家人一欄、缺口綠黃紅，不顯示任何商品推薦。
  • 要列印：用手機瀏覽器或後台按「列印／存成 PDF」（LINE 裡多半不能印）。頁尾會附免責文字與你的姓名、所屬機構、登錄字號。
  • 上課用講師發的示意保單，不要拿真客戶的保單。

3. 早報、提醒、祝福、行事曆

早報

  • 每天 07:30（後台「保險業務 → 關懷 → 祝福與行事曆」可改），一天一則；沒事的那天不發。

提醒（工作台「提醒」頁）

  • 生日、年齡里程碑、保單週年、繳費日、滿期、自訂。
  • 處理：已處理／延後（最多 90 天）／略過。

祝福（工作台「祝福」頁）

  1. 系統先產生草稿（只有連了 LINE 的客戶才會有）。
  2. 逐則預覽，可改字，按「確認」或「全部確認」。
  3. 預設 09:00 送出。沒確認就不發。
  • 場合：國曆生日、農曆生日、20 個台灣節日、紀念日、保單週年、繳費提醒。
  • 也可以改成自動發送。
  • 改字遇到健康字詞會直接擋。

行事曆

  • 日、週、月三種檢視；待辦可完成、延後一天、刪除。
  • 「同步到手機行事曆」產生私密網址，貼到 Google 日曆（以網址新增）或 iPhone 日曆（加入已訂閱的行事曆）。網址只顯示一次，外流就重新產生。

記住：早報、祝福從你的官方帳號推播，會用到你官方帳號方案的訊息則數。

4. 客戶在 LINE 看保單、問保單

步驟（業務）

  1. 家庭明細點客戶旁的「LINE 連結」，產生一次性連結（72 小時、只能用一次）。
  2. 傳給客戶本人。
  3. 客戶打開、同意個資告知事項，就完成連結。

客戶看得到什麼

  • 自己是要保人或被保險人的保單、自己投保的未成年子女保單。
  • 家庭共享要雙方都開；配偶替成年子女投保的，成年子女本人也要開。
  • 保單號碼只顯示末 4 碼；看不到照片和你的備註。

客戶可以問：保額、醫療日額、下次繳費日、繳別、保費、滿期日、保險公司。可以在「問我的保單」頁問，也可以直接在官方帳號聊天室打字。每則回答附「實際權益以保單條款為準」。 不回答：理賠、條款、「會不會賠」，會請客戶按「轉真人」，訊息進到你的「客戶訊息」。

客戶訊息

  • 新訊息會通知你本人（不含內容；晚上 10 點到早上 7 點不推；同一位客戶 30 分鐘最多一次）。
  • 回覆時含「保證、穩賺、最高」等字句會先提醒，可改寫或仍要送出。
  • 含健康字詞會直接擋，請改說法或打電話。

5. AI 助理與合規副駕

在官方帳號聊天室對助理說（用你綁定業務的 LINE）

  • 「查王小明」：看客戶摘要
  • 「記：王小明想了解退休規劃」：建筆記草稿
  • 「下週二下午三點約王小明」：建約訪草稿
  • 草稿要到工作台「助理」頁按確認才會存。

記住

  • AI 只產生草稿，你確認才生效。
  • 送 AI 前會把姓名、家人、地址、Email、保單號碼等換成代號或遮掉；含健康字詞的內容不送。
  • 不推薦商品、不給投資建議。
  • 合規副駕只提醒不擋，也不代替所屬機構的核可。
  • 語音面談整理預設關閉；要開，必須你本人在後台看過告知並勾選，也要先跟客戶說明錄音會送雲端 AI 轉文字（轉完即丟）。
  • 你綁定業務的 LINE 在自己官方帳號裡說的話，都由助理接走，不會進客戶訊息。

6. 數位名片、轉介紹、匯入舊名單

數位名片（工作台「我的名片」）

  • 姓名、所屬機構、登錄字號自動帶入，名片一定標示所屬機構。
  • 「保證、穩賺、保本、最高、唯一、報酬率、退佣、保費折扣、優惠、限時」等字會直接擋。
  • 個人版送出就公開，可以用 LINE 分享名片。

轉介紹

  • 三種來源：你登錄、對方在名片頁留資料、客戶轉傳帶碼連結；都會記「誰介紹的」。
  • 只能送關懷禮。系統擋退佣、保費、折扣、現金、紅包、禮金、點數等字眼。

匯入舊名單（後台「保險業務 → 資料與設定 → 匯入客戶與保單」）

  1. 下載範本，或用自己的表格（欄位名稱接近會自動對應）。
  2. Excel 另存 CSV（Big5 會自動辨識）或直接選 .xlsx；一次最多 2000 列、2 MB。
  3. 預覽、修正欄位對應，錯誤列可下載修改。
  4. 勾「已向名單上每一位當事人說明並取得同意」，選取得方式，按「匯入」。
  • 檔案裡有病史、體檢、身高體重、身分證字號、銀行帳號、卡號等欄位，整份會擋下，請先刪掉那幾欄。

第五部分：五條紅線

  1. 不收健康資料：病歷、醫療、健康檢查是個資法第 6 條的特種個資。不寫在備註、拜訪紀錄、行事曆、訊息裡。核保由保險公司依健康告知書決定。字詞清單只是防呆，不在清單上的也可能是健康資料，責任在你。
  2. 每位客戶都要有同意紀錄：新增時勾選並選取得方式；告知事項改版後顯示「需重新同意」，向客戶說明後按「補登同意」。
  3. 招攬規範：對外訊息附姓名與所屬機構；不寫保證、穩賺、最高、第一、唯一、比存款好；不提特定商品、報酬、優惠；不送退佣、保費、現金。
  4. 尊重當事人權利：客戶要查閱或副本 →「匯出資料」；要刪除 →「刪除」（徹底刪除，無法復原，拜訪紀錄去識別保留）。
  5. 代登入不能代表你：同意聲明、資料控制者、開通確認、開啟語音等，只能你本人登入操作。

常見問題

Q：系統會收客戶的病歷嗎？ 不會，而且是刻意設計的。沒有任何健康欄位，也不收身分證字號。

Q：客戶要求刪除資料怎麼辦？ 後台「客戶與家庭」按「刪除」，客戶資料、家庭關係、保單、保單照片、提醒會徹底刪除；傳給他的訊息全文一併刪除；拜訪紀錄保留但去識別。每次刪除都有紀錄（不記姓名）。

Q：系統會幫我推薦商品嗎？ 不會。保障總表只顯示保額與缺口，AI 被要求推薦會直接拒答。

Q：祝福會不會沒看過就送出去？ 預設是早上一鍵確認，沒確認就不發。你也可以改成自動發送，使用前請確認設定。

Q：可以線上投保或收保費嗎？ 不行，保客+ 沒有線上投保與收款。

Q：業績會幫我算佣金嗎？ 不會，業績只登錄 FYP、FYC。

Q：官方帳號是誰的？ 是你自己的。好友、訊息費用都屬於你自己的帳號方案。

二、LINE 帳號安全（30 分鐘）

S0 開場：為什麼先談帳號安全（5 分）

  • 目標：讓學員理解「個人 LINE＝客戶資料的鑰匙」。
  • 講師說：
    • 等一下你的個人 LINE 會綁成保客+ 的業務工作台，打開就看得到你所有客戶與保單。手機 LINE 被盜，等於客戶名單被盜。
    • 官方帳號被盜，對方可以用你的名義傳訊息給客戶，詐騙、亂發商品訊息，責任落在你身上（招攬規範、個資法）。
    • 盜號最常見的入口不是駭客技術，而是「把簡訊驗證碼給了別人」。
  • 學員做：聽，舉手回答「誰曾收過朋友借錢、要點數卡的訊息」。
  • 畫面：冒名借錢訊息示意圖（自己做，不要用真人截圖）。

S1 個人 LINE 帳號防盜設定（10 分）

  • 目標：知道 8 個關鍵設定在哪裡、要設成什麼。
  • 講師說（每項一句「為什麼」）：
    1. 密碼：設高強度、不與其他網站共用。
    2. Email：綁定並確認收得到信（找回帳號、忘記密碼用）。
    3. 電話號碼：確認收得到簡訊；電信語音信箱建議關閉或改密碼（有過利用語音信箱取得驗證碼的手法）。
    4. 綁定 Apple 或 Google 帳號：依媒體 2026-04 報導，被盜時有綁定的帳號較有機會找回原帳號；沒綁的通常只能建新帳號、付費商品補回（約 7～14 個工作天）。
    5. 允許自其他裝置登入：平常關閉，要用電腦版時再暫時打開。
    6. 登入中的裝置：定期檢查，看到不認得的裝置就登出並改密碼。
    7. 電腦版／iPad 登入：建議用 QR Code 登入，不在公用電腦登入；有開生物辨識（Face ID／指紋）的手機可以進一步關閉密碼登入，電腦版只能掃碼。
    8. Letter Sealing（訊息加密）：保持開啟；依媒體報導 2026 年 4 月起已改為預設且無法關閉，學員只要確認即可。
    9. 加好友設定：關閉「自動加入好友」與「允許被加入好友」（避免陌生人與假帳號主動加你），可開啟「阻擋訊息」。
  • 補充觀念：
    • 簡訊驗證碼絕不給任何人，包含「LINE 客服」「朋友」「投票活動」。LINE 的任何登入網頁都不會要你輸入簡訊驗證碼。
    • 可疑連結：短網址、要你「登入領好康」「綁定 Apple／Google 帳號」的頁面一律不點。
    • 假冒官方帳號：真的官方帳號名稱旁有認證標章；不確定時從公司官網或名片上的 QR Code 加入，不從陌生訊息加。
  • 畫面：手機 LINE「設定 → 我的帳號」「設定 → 隱私設定」「好友」設定頁截圖（以上課當天的 LINE 版本實拍，選單名稱可能因版本略有不同）。

S2 官方帳號與 Business ID（5 分）

  • 目標：會檢查官方帳號的成員權限，懂二階段驗證。
  • 講師說：
    • LINE 官方帳號後台（Official Account Manager）用 LINE Business ID 登入。以 Email 註冊的 Business ID 自 2024-09-03 起預設開啟二階段驗證（Email 驗證碼或驗證器 App），備用碼要存好。
    • 權限分級（第三方教學整理，名稱以後台為準）：管理員（全部功能、能管成員）、操作人員（群發、聊天、看分析，不能管成員）、操作人員（無傳送權限）、操作人員（無查看分析權限）。
    • 原則：管理員只給自己（或最信任的一人）；助理、小編給操作人員；離職或合作結束當天就移除。
    • 被盜徵兆：出現你沒加的成員、群發紀錄有你沒發的訊息、自動回應被改、聊天裡有你沒回的話、收到陌生登入通知。
    • 開發者那一端：LINE Developers Console 的 Provider 成員也要檢查，那裡拿得到 Channel Secret 與 Access Token。
  • 畫面：官方帳號後台「設定 → 權限管理」截圖；Developers Console 的 Provider「Roles」截圖。

S3 被盜了怎麼辦（6 分）

  • 目標：拿到一張「照順序做」的處置清單。
  • 講師說：
    • 個人 LINE 被盜：
      1. 還能登入：立刻改密碼、檢查並登出不認得的裝置、關閉「允許自其他裝置登入」。
      2. 不能登入：到 LINE 客服的問題回報表單，登入頁選「不登入並繼續操作」，類別選帳號被盜用，由本人填寫（官方說明通常 24 小時內回覆）。
      3. 用其他管道（電話、簡訊、另一個 LINE）通知好友與客戶「這段時間收到我要錢或連結的訊息都不是我」。
      4. 保客+ 這邊：見下面第 3 點。
    • 官方帳號被盜：
      1. 還進得去：先移除可疑成員、改 Business ID 密碼、確認二階段驗證；檢查群發、自動回應、圖文選單有沒有被改。
      2. 進不去：聯絡 LINE 官方帳號客服，必要時請 LINE 先停用帳號。
      3. 到 Developers Console 重新發行 Channel Access Token（舊的立刻失效），Channel Secret 也重新發行；檢查 Webhook 網址有沒有被改。
      4. 回保客+ 後台「系統設定 → LINE 串接 → LINE 參數」貼上新的 Access Token（與新的 Secret），按「儲存並驗證」，再按「測試連線」看到官方帳號名稱才算完成。只換 Token 的話其他欄位留空即可，留空代表不變更。
    • 保客+ 這邊要做的（個人 LINE 被盜時）：
      1. 用新的 LINE 重新綁定業務工作台：後台「我的業務資料」按「產生綁定連結」，在新 LINE 打開按「確認綁定」，舊的綁定自動解除。
      2. 手機日曆訂閱網址重新產生（工作台「行事曆 → 同步到手機行事曆」），舊網址立刻失效。
      3. 後台密碼一起換。
    • 注意：換成「另一個官方帳號」跟「同一個帳號換金鑰」不一樣。換帳號後，業務 LINE 綁定要全部重新做；同一帳號重發金鑰只要更新後台金鑰。

S4 實作：每人當場檢查（4 分）

  • 學員做：拿講義的「LINE 安全檢查清單」逐項打勾，完成舉手。
  • 助教：巡場，協助找選單。

三、保客+ 3 小時

1. 價值與情境：業務的一天（15 分）

  • 目標：讓學員知道「我每天會在哪個時刻用它」，建立接下來操作的動機。
  • 講師說：
    • 四個痛點：生日週年繳費日記在本子常漏；一家人保單散在各家公司整理很花時間；客戶訊息怕講錯話；個資要求多不知道怎麼留紀錄。
    • 一天的節奏：
      • 早上 07:30：LINE 收到一則早報（今日行程、今天先處理這幾位、到期提醒、待確認祝福、久未聯絡）。
      • 早上：在 LINE 工作台「祝福」頁逐則看草稿、按確認，09:00 以你的官方帳號送出。
      • 白天拜訪：打開家庭保障總表跟客戶談，回來記一筆拜訪。
      • 客戶在 LINE 問「我下次什麼時候繳費」：系統依登錄的保單自動回答；理賠條款問題轉給你。
      • 晚上：在官方帳號聊天室對助理說「記：王小明想了解退休規劃」，草稿確認後存成筆記。
    • 個人版的意思：你自己就是管理者也是業務；官方帳號、好友、訊息費用都屬於你自己。
    • 三條底線先講：不收健康資料、AI 只出草稿要你確認、對外訊息附你的姓名與所屬公司。
  • 學員做：聽；在講義寫下「我最想先解決的一個痛點」。
  • 示範畫面：業務工作台「今天」頁、早報訊息、家庭保障總表（示範帳號，示意資料）。

2-3 三站流程（每人自己的後台、自己的 LINE 後台）

講師先用投影整段示範一次（7 分），學員再自己做（31 分），最後 7 分鐘全場驗收。

第一站：Messaging API 與 Webhook（約 8 分）

  1. 用我們發的帳號登入自己的後台。
  2. 進「系統設定 → LINE 串接 → LINE 參數」。
  3. 「Messaging API Channel」貼上 Channel ID（10 碼數字）、Channel Secret、Channel Access Token（長期），按「儲存並驗證」，看到綠色「已驗證」與官方帳號名稱。
  4. 儲存成功後，系統會自動設定 Webhook：把網址設成你的專屬網址、讀回「Use webhook」開關、請 LINE 送一次測試。看卡片下方的燈號：綠色「Webhook 已自動設定完成」就完成；黃色「Use webhook 開關目前是關閉的」，就到 LINE Developers Console → 該 Messaging API channel → Messaging API 分頁，自己把「Use webhook」打開（LINE 沒有開放程式代按，一定要本人點），回後台按「檢查 Webhook」直到綠燈。不用再手動貼 Webhook URL，也不用按 Verify。其他黃、灰燈處理見卡關排除表。
  5. 到 LINE 官方帳號後台「回應設定」關閉自動回應訊息（不關會跟系統回覆打架）。
  6. 上線後補截圖：Webhook 綠燈與黃燈畫面。

第二站：LINE Login 與自動建立 LIFF（約 10 分）

  1. 同一頁的「LINE Login Channel 與 LIFF」貼上 LINE Login Channel ID、Channel Secret，按「儲存」。LIFF ID 不用貼。
  2. 按「自動建立／校正 LIFF」：系統會用 LINE 的 API 建好 LIFF（Size＝Full、profile／openid／chat_message.write 三個 Scopes、加好友選項 On (Aggressive)、Endpoint 指向你的專屬網址），並把 LIFF ID 自動存回設定。畫面會逐項列出「還要你手動做」的項目。
  3. 手動做這三項（LINE 沒有開放 API）：到 LIFF 分頁打開 shareTargetPicker；到 LINE Login channel 的 Basic settings 把 Linked LINE Official Account 選成自己的官方帳號（若系統因為還沒連結而把加好友選項先設成關閉，連結後再按一次「自動建立／校正 LIFF」）；把畫面上的 Callback URL 貼到 LINE Login 設定（結尾斜線不能少）。另確認 channel 的 Region 是 Taiwan（建立時選的，建好不能改）。
  4. LINE Login channel 狀態改成「已發布（Published）」。這一步最常漏，而且自己測不出來（開發者本人永遠正常），所以第三站要用夥伴的手機驗。
  5. 上線後補截圖：自動建立 LIFF 的結果清單。

第三站：首次設定、綁定工作台、同 Provider 檢查、加好友（約 13 分）

  1. 後台「保險業務 → 團隊與業績 → 組織與業務」（個人版頁名是「我的業務資料」）完成首次設定：選職業別、填本人資料（姓名、手機、所屬機構、登錄字號選填）、資料控制者（預設帶自己的姓名與手機）、逐項勾選開通確認、按「完成設定」。
    • 這一步必須本人登入勾選。平台人員代登入不能替你勾，所以課前我們不會先幫你做。
  2. 畫面出現綁定連結，傳到自己的 LINE，在手機上打開，按「確認綁定」，進到業務工作台。連結 72 小時有效、只能用一次。
  3. 用自己的 LINE 加自己的官方帳號為好友（早報要好友才收得到）。
  4. 同一個 Provider 檢查（半自動，要用夥伴的手機，因為夥伴不是你這個 LINE Developers 的管理員，測得出 Published）：
    1. 你在 LINE 參數頁最下方按「開始檢查」（15 分鐘內有效）。
    2. 夥伴用他的 LINE 掃你的官方帳號 QR Code 加好友。
    3. 夥伴用同一支手機打開卡片上顯示的 LIFF 網址，登入。若手機出現「400 Bad Request／developing status」，就是 Login channel 還沒發布，回第二站第 4 步。
    4. 你回後台按「查看結果」：綠色「通過」＝兩個 channel 在同一個 Provider，而且已發布；紅色「查不到」（確定已加好友）＝不在同一個 Provider，到補救站；黃色「還沒收到 LIFF 登入」＝夥伴手機還沒登入完。
    5. 兩人互換再做一次。
  5. 夥伴傳一句「測試」。你到後台「訊息發送 → 會員留言」確認看得到這則訊息，代表 webhook 通了（此頁需開通訊息發送模組，開通組合待確認；沒有此頁時改看會員列表是否出現夥伴）。
  6. 上線後補截圖：同 Provider 檢查的綠燈、紅燈畫面。

3. 功能實作逐段

功能 1：客戶與家庭建檔、取得同意（10 分）

  • 目標：會建家庭、加成員、選取得同意方式，懂「以家庭為單位」。
  • 講師說：
    • 家庭是單位：一家人一個畫面；沒有 LINE 的小孩、長輩也建成成員。
    • 成員欄位：姓名、性別、生日、手機、職業類別、年收入級距、備註。年收入級距會影響保障缺口的壽險建議。
    • 新增成員一定要勾「已向當事人說明告知事項並取得同意」並選取得方式（書面、口頭、LINE 對話），沒勾不能存。未成年子女、長輩可由同戶家人代為同意。
    • 分級 A、B、C、D 是你自己的判斷，系統不算；分級會決定「久未聯絡」幾天提醒（預設 A 30 天、B 60 天、C 90 天）。
    • 家庭關係：配偶、子女、父母、兄弟姊妹、其他。
    • 備註打到疾病字詞會跳提醒（例如「高血壓」）：本系統不收健康資料。
  • 學員做：在工作台建「示範家」，加 3 位成員（本人、配偶、未成年子女），其中一位生日設在未來 7 天內（為明早的早報與祝福做準備）；備註故意打「高血壓」看提醒，再刪掉。
  • 示範畫面：工作台「我的家庭」→ 家庭明細 → 新增成員（同意勾選框）；健康字詞提醒。

功能 2：保單登錄、拍照讀保單、家庭保障總表（20 分）

  • 目標：登錄一張保單（含保障明細），看到保障總表與缺口燈號。
  • 時間說明：比原本多 5 分鐘，是串接省下來的，用在學員實際動手：多登錄一張保單，並用示意保單走一次拍照讀取的逐欄核對。
  • 講師說：
    • 保單欄位：保險公司（各家都能登）、商品名稱、保單號碼、要保人、被保險人、生效日、滿期日、繳別、繳費年期、保費、幣別、繳費方式（只記類別，不記卡號帳號）、狀態。
    • 保障明細（主約、附約、保額、醫療記住院日額）才是保障總表計算的依據；沒填明細，保單只會出現在清單裡。
    • 拍照讀保單：只拍保單首頁，不要拍健康告知書。讀出來是草稿，每欄標「已讀取／請核對／看不清楚未填入」，看不清楚的不預填；逐欄核對按「確認儲存」才建立。一次最多 6 張（首頁、附約明細、保險存摺截圖、繳費通知單）。偵測到健康告知頁整張丟棄。每月有使用上限。
    • 家庭保障總表：每位家人一欄看壽險、重大疾病、意外、失能、長照、醫療日額、年繳保費；缺口綠黃紅。不顯示任何商品推薦。
    • 列印：在 LINE 裡多半不能列印，用手機瀏覽器或後台按「列印／存成 PDF」，頁尾固定附免責文字與你的姓名、所屬機構、登錄字號。
  • 學員做：手動登錄一張示意保單（講師發的示意保單，虛構資料），填一筆主約與一筆醫療附約；打開保障總表看燈號。
  • 示範畫面：保單表單、拍照讀取草稿（欄位標示）、保障總表、列印版頁尾。
  • 待確認：拍照讀保單在正式環境以真實保單與 AI 服務的實測尚未完成。課前要用示意保單實測一次；若沒過，現場只示範手動登錄，拍照讀取用截圖說明。示範用的保單一律是虛構資料，不要拿真客戶的保單上課。

功能 3：早報、提醒、祝福、行事曆（12 分）

  • 目標：知道明天早上會收到什麼、怎麼確認祝福、怎麼處理提醒。
  • 講師說：
    • 早報：每天 07:30（可在「保險業務 → 關懷 → 祝福與行事曆」改），一天一則，包含今日行程、今天先處理這幾位、送件回覆期限、待確認祝福、到期提醒、年度保單檢視、生命事件、久未聯絡。當天什麼事都沒有就不發。
    • 提醒：生日、年齡里程碑（6、12、18、22、40、50、60、65 歲）、保單週年、繳費日、滿期、自訂。處理方式：已處理、延後（最多 90 天）、略過。
    • 祝福：國曆生日、農曆生日、20 個台灣節日（11 個預設開）、客戶紀念日、保單週年與繳費提醒。系統先產生草稿（只有連了 LINE 的客戶才會產生），預設「早上一鍵確認」，沒確認就不發；也可選自動發送。發送時間預設 09:00。
    • 內建祝福範本依職業別各一套，不含商品、報酬或優惠字眼；簽名檔自動附在最後。
    • 祝福改字遇到健康字詞會直接擋，不能強制送出（客戶會收到的訊息）。
    • 行事曆：日、週、月；可產生私密網址訂閱到 Google 或 iPhone 日曆（單向、網址只顯示一次、預設姓名遮罩）。
    • 訊息費用：早報、祝福是從你的官方帳號推播，會用到你官方帳號方案的訊息則數。
  • 學員做：在工作台「行事曆」產生手機日曆訂閱網址並加到自己手機日曆（時間不夠可課後）；到「提醒」頁新增一則自訂提醒。
  • 示範畫面：早報訊息、「祝福」頁（逐則預覽、全部確認）、「提醒」頁、行事曆週檢視、iCal 設定。

功能 4：客戶在 LINE 看保單、問保單、客戶訊息（15 分，兩人一組）

  • 目標：完整走一次「客戶連結 LINE → 看保單 → 問保單 → 轉真人 → 業務回覆」。
  • 講師說：
    • 客戶連結：在家庭明細點客戶旁的「LINE 連結」產生一次性連結（72 小時、只能用一次），傳給客戶本人。客戶打開、閱讀並同意個資告知事項後完成連結。告知事項上的資料控制者就是你（首次設定填的）。
    • 客戶看得到：自己是要保人或被保險人的保單、自己投保的未成年子女保單。家庭共享要雙方都開；配偶替成年子女投保的，要成年子女本人也開。保單號碼只顯示末 4 碼，不顯示照片與你的備註。
    • 問保單：保額、醫療日額、下次繳費日、繳別、保費、滿期日、保險公司。每則附「實際權益以保單條款為準」。理賠、條款、「會不會賠」一律不回答，請客戶按「轉真人」。客戶也可以直接在官方帳號聊天室打字問。
    • 客戶訊息：客戶在官方帳號傳的訊息進到你的工作台「客戶訊息」；新訊息通知你本人（不含內容，晚上 10 點到早上 7 點不推，同一位客戶 30 分鐘最多一次）。
    • 回覆前會先過合規副駕：含「保證、穩賺、最高」等字句會提醒（可改寫或仍要送出）；含健康字詞直接擋、沒有仍要送出。
  • 學員做（A、B 互換各做一次）：
    1. A 在自己的工作台替 B 建一個測試家庭（姓名可用 B 同意的暱稱），登錄一張示意保單，被保險人是 B。
    2. A 產生 B 的 LINE 連結，用 LINE 傳給 B。
    3. B 打開、同意告知事項，看到「我的保單」。
    4. B 在 A 的官方帳號聊天室打「下次什麼時候繳費」，收到系統回答卡片。
    5. B 打「這樣會不會賠」，按「轉真人」（或直接傳一句話）。
    6. A 收到通知，到「客戶訊息」回覆。先打「保證理賠沒問題」看合規副駕提醒，再改寫送出。
  • 示範畫面：客戶的「我的保單」、問答卡片、轉真人、業務「客戶訊息」頁、合規副駕提醒畫面。
  • 待確認：
    • 同一支 LINE 能否同時是自己的業務與自己的客戶，說明書沒寫。所以一律用夥伴的 LINE 當客戶，不讓學員自己扮客戶。
    • 綁定業務身分的 LINE 在自己官方帳號聊天室打字，會被 AI 助理接走，所以客戶角色一定要用另一支 LINE。
    • 通知只在 07:00～22:00 推，課程時段內沒問題。

功能 5：AI 助理與合規副駕（8 分）

  • 目標：會在官方帳號聊天室對助理說三種話，知道 AI 的界線。
  • 講師說：
    • AI 只產生草稿或建議，你按確認才生效，都標「AI 草稿」。助理只查你自己的客戶，不能刪資料、不能直接傳訊息給客戶。
    • 送 AI 前先去識別：客戶姓名換代號，家人姓名、稱呼、地址、Email、保單號碼遮掉，生日改年齡區間；查不到要遮的資料時這次就不用 AI。含健康字詞的內容不會送出。
    • 不推薦商品、不給投資建議，被要求時直接拒答。
    • 三種說法：「查王小明」（客戶摘要）、「記：王小明想了解退休規劃」（筆記草稿）、「下週二下午三點約王小明」（約訪草稿）。草稿要到工作台「助理」頁按確認才存。
    • 合規副駕：貼一段文字檢查「保證、穩賺、最高、第一、唯一、比存款好、退佣、送保費」等字句，只提醒不擋，也不代替所屬公司的核可。
    • 語音面談整理預設關閉：開啟要本人在後台看過告知並勾選（錄音送雲端 AI 轉文字、轉完即丟），要先在告知事項向客戶說明。
    • 額度：每人每天有額度，用完時規則式功能照常可用。
  • 學員做：在自己官方帳號聊天室打「查（示範家成員姓名）」、「記：（成員）想了解子女教育金」，到工作台「助理」頁確認筆記；在「發送前檢查」貼一句「這張保單穩賺不賠」看提醒。
  • 示範畫面：聊天室裡的助理回覆、「助理」頁草稿確認、合規副駕結果。
  • 待確認：AI 早報理由句、約時間、祝福草稿、面談整理這些需要呼叫 AI 的功能，正式環境的 AI 服務與點數設定課前要實測；「查」與「記」是規則式，比較穩。若 AI 未通，只示範「查」「記」與合規副駕。

功能 6：數位名片、轉介紹、匯入舊名單（7 分，示範為主）

  • 目標：知道開發新客戶與搬舊資料的入口。
  • 講師說：
    • 數位名片：工作台「我的名片」，姓名、所屬機構、登錄字號由業務資料帶入，名片上一定標示所屬機構。「保證、穩賺、保本、最高、唯一、報酬率、退佣、保費折扣、優惠、限時」等字直接擋。個人版送出即公開。可用 LINE 分享名片卡片。
    • 轉介紹：業務登錄、名片頁留資料（對方要同意告知事項）、客戶轉傳帶碼連結，三種來源都記「誰介紹的」。轉介紹只能送關懷禮，系統擋退佣、保費、折扣、現金、紅包、禮金、點數等字眼。
    • 匯入：後台「保險業務 → 資料與設定 → 匯入客戶與保單」，Excel 另存 CSV（Big5 會自動辨識）或 .xlsx，一次最多 2000 列、2 MB。檔案裡有病史、體檢、身分證字號、銀行帳號、卡號等欄位會整份擋下。匯入前要勾「已向名單上每一位當事人說明並取得同意」，只能本人勾。
  • 學員做：看示範；有時間的人編輯自己的名片。
  • 示範畫面：名片編輯、名片分享卡片、匯入預覽與錯誤列。

合規內建與紅線總整理（8 分）

  • 目標：學員能說出五條紅線。
  • 講師說：
    1. 不收健康資料：病歷、醫療、健康檢查是個資法第 6 條的特種個資。系統沒有健康欄位，也不收身分證字號。備註打到疾病字詞會先攔下（筆記類可堅持送出並留紀錄）；客戶會收到的訊息（一對一回覆、祝福改字）遇健康字詞直接擋。字詞清單只是防呆，不是判斷，責任在你。
    2. 告知與同意：每位客戶都要有同意紀錄與取得方式；告知事項改版後，舊同意的客戶會顯示「需重新同意」。
    3. 招攬規範：對外訊息附姓名與所屬機構；不寫保證、穩賺、最高、第一、唯一；不提特定商品、報酬、優惠（保險業務員管理規則第 19 條）；不送退佣、送保費、現金。轉介紹只送關懷禮。
    4. 當事人權利：客戶要查閱或副本，用「匯出資料」；要刪除，用「刪除」（徹底刪除，保單照片一起移除，拜訪紀錄去識別保留）。每次都有紀錄。
    5. 代登入不能代表你：同意聲明、資料控制者、範本核可、開啟語音、開通確認，平台人員一律不能代按。
    • 職業別提醒：銀行理專先確認所屬銀行允許以本系統保存客戶資料；獨立理財顧問未取得投顧執照者不得提供特定有價證券的投資建議。
    • 系統內建的告知事項範本僅供參考，正式使用前請所屬公司法遵或律師覆核。
  • 畫面：五條紅線一頁一條。

4. 實戰演練（20 分，兩人一組）

每組抽一張情境卡，做完換下一張。助教巡場看是否踩到紅線。

  • 情境一：新客戶建檔到第一次關懷（8 分）
    • 剛在講座認識陳先生一家四口（夫妻、10 歲女兒、70 歲母親，皆虛構）。建家庭、取得同意（口頭）、登錄先生的一張壽險與一張醫療附約、看保障總表缺口；為女兒下週的生日確認一則祝福草稿。
    • 檢核：同意方式有選、未成年由家人代為同意、保障明細有填、祝福沒有商品字眼。
  • 情境二：客戶在 LINE 問理賠（6 分）
    • 夥伴扮客戶在你的官方帳號打「我上個月住院，這張會賠嗎？」，你要怎麼處理？
    • 檢核：系統不自動回答理賠問題；回覆時不寫病名（會被擋）；改用「我打電話跟您確認細節」之類說法或電話聯絡；不承諾理賠結果。
  • 情境三：帳號出事了（6 分）
    • 早上發現自己的個人 LINE 被登出、朋友說收到你借錢的訊息。請兩人一起照處置清單排出順序：個人 LINE、通知客戶、保客+ 重新綁定、行事曆網址重產、後台密碼。
    • 檢核：順序正確、知道重新綁定入口在「我的業務資料」。

時間不夠時刪情境三，改到課後作業。

5. 課後作業、支援方式、Q&A（10 分）

  • 課後作業（一週內）：
    1. 明早 07:30 確認收到早報；在「祝福」頁確認一則祝福（今天建的生日成員）。
    2. 匯入或手動建 10 戶真實客戶，每一位都取得同意並選方式；備註不寫健康資料。
    3. 替其中 3 位客戶產生 LINE 連結，請他們完成連結。
    4. 用「查」「記」對助理說 3 次。
    5. 完成 LINE 安全檢查清單剩下的項目。
  • 課後要刪的：上課建的示範家庭與夥伴測試家庭，在後台「客戶與家庭」按刪除（徹底刪除），夥伴的 LINE 連結一起清掉。
  • 支援方式（請 Shark 確認後填入）：LINE 客服管道、回覆時段、串接未完成者的 1 對 1 時段。
  • Q&A：常見問題見講義最後一節。
  • 不談價格，不談上線狀態。被問到價格：依方案規劃，課後個別說明。

四、課前準備清單（講師與助教）

  • 每位學員：後台網址、帳號、初始密碼（一人一張紙條）；確認每個租戶的會員端、後台網域都打得開（新租戶要另外加網域、等 SSL）。
  • 每個租戶都已開通保客+ 並設為個人版；確認「系統設定 → LINE 串接 → LINE 參數」租戶管理員看得到。
  • 用一個個人版測試租戶完整彩排一次：串接、首次設定、綁定、早報、客戶連結、問保單、轉真人通知、助理「查」「記」、拍照讀保單、列印。
  • 示意保單 3 張（虛構姓名、虛構保單號碼，不要用真保單）。
  • 情境卡、完成燈號紙卡、卡關排除表（每組一份）。
  • 場地網路：30 人同時操作，準備備援手機熱點；投影要能投手機畫面。
  • 助教：每 6～8 人一位，加 1 位補救站；課前先看過卡關排除表並各自串過一次。
