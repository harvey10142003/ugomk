先讀這裡：這份說明書怎麼用

這是一份「照著做就會」的操作手冊，專給第一次用保客+ 的你。每一節都用同樣的順序寫：這是做什麼的、在哪裡打開、一步一步做、做完你會看到什麼、小提醒。

兩個地方會用到保客+

後台：用電腦瀏覽器打開的管理網頁，要輸入帳號密碼。拿來做「設定」和「整理資料」。

業務工作台：在手機 LINE 裡打開的小網頁（技術上叫 LIFF，意思就是「在 LINE 裡面打開的小網頁」）。你每天跑客戶時用它，不用輸入帳號密碼，因為它認得你的 LINE。

文件裡的記號

圖片上的紅框和1、2數字，對應圖片旁邊同樣編號的說明。

「方框文字」代表畫面上真的有這個按鈕或選項，照著找就對了。

用到的專有名詞，第一次出現就會用白話解釋，最後面也有「名詞小辭典」。

關於圖片

圖中的客戶、保單與姓名全部是為了教學虛構的示範資料。本說明書的截圖取自示範環境（團隊版），你的畫面是個人版：少了「組織、主管、團隊、增員、業務儀表板」這幾個團隊才需要的功能，其他畫面相同。若你的畫面和圖有一點點差異（例如底部少一個「團隊」），是正常的。

建議的閱讀方式

第一次請依 ① → ⑧ 的順序做，每一節都做完再往下。⑨ 以後是進階功能，需要時再回頭查。卡住了，直接跳到「⑬ 常見問題」。左邊（手機是上方）的目錄和搜尋框可以幫你快速找到想看的那一節。

想列印帶走？按瀏覽器的列印，選「另存為 PDF」即可，版面已經為列印調整過。

1

開始前準備

先確認你手上有「自己的 LINE 官方帳號」和「已串接好」的資料，保客+ 才能替你傳訊息。這一步在課前講義裡已經帶你做過了。

保客+ 個人版用的是你自己的 LINE 官方帳號：加你好友的客戶、傳訊息的費用，都是你自己的官方帳號，我們不代付，也不會搬走。

要準備的東西說明
LINE 官方帳號就是客戶在 LINE 上加的那個「店家帳號」。已經有在經營的可以直接接，好友全部保留。
Messaging API讓保客+ 可以用你的官方帳號收發訊息的開關（一種「對外接口」）。
LINE Login channel 與 LIFF讓客戶和你自己能在 LINE 裡打開保客+ 小網頁的設定。LIFF 由系統自動幫你建立，不必手動做。
電腦 + 手機 LINE電腦做設定，手機用工作台。
後台網址、登入帳號與密碼上課時由講師施允瀚提供。

申請步驟與串接的每一個畫面，請看課前講義：保客+ 課前準備講義（24 張截圖，一步一步）。

完成後你會看到官方帳號可以正常登入，Messaging API 已開啟，你知道 Channel secret 與 Access token 要貼到哪裡（上課時會一起貼進後台「系統設定 → LINE 串接 → LINE 參數」）。
還沒接好 LINE 也能先用

沒接好 LINE 之前，後台仍可建立客戶、保單；只是拿不到手機工作台的綁定連結，也沒辦法傳訊息。建議先完成 ②，再回來補串接。

2

第一次登入後台，完成個人版首次設定

第一次上線一定要做的設定：登入後台、填你的基本資料、勾選開通確認。沒做完這一步，後台不能建立客戶。

2-1　登入後台

在哪裡電腦瀏覽器 → 講師給你的後台網址

  1. 用電腦（Chrome、Edge 都可以）打開講師給你的後台網址。
  2. 輸入電子郵件和密碼（上課時由講師提供）。
  3. 按綠色的登入。
完成後你會看到進入後台首頁（儀表板）。左邊是功能選單，頂端有說明與帳號。
密碼不要外流

後台能看到你所有客戶的資料。不要把帳號密碼傳到群組、也不要存在公用電腦。

2-2　找到「保險業務」選單

在哪裡後台左邊選單 → 保險業務

  1. 在左邊選單找到保險業務，按一下展開。
  2. 展開後有幾個分類：客戶開發、客戶與規劃、保單服務、關懷、合規與品質、資料與設定等，把滑鼠移上去會再展開細項。
  3. 本說明書寫的路徑，例如「保險業務 → 資料與設定 → 模組設定」，就是照這個選單一層一層點。
選單找不到「保險業務」？

代表這個租戶還沒開通保險模組，請聯絡講師。

2-3　完成個人版首次設定

在哪裡保險業務 → 團隊與業績 → 組織與業務（個人版的頁面標題會顯示成「我的業務資料」）

  1. 打開上面那一頁。個人版沒有「組織單位」，直接是一張設定表單。
  2. 選職業別：保險業務員、銀行理專或獨立理財顧問。職業別只影響文字（稱呼、招攬規範提醒、內建祝福範本），不會增減功能，之後可以改。
  3. 填本人資料：姓名、手機、所屬公司（所屬機構）、登錄字號（選填）。所屬公司與字號由你本人負責，系統不會驗證，只會印在訊息簽名檔和報表頁尾。
  4. 確認資料控制者：預設帶入你的姓名與手機。客戶看到的「個人資料蒐集告知事項」會寫這裡的名稱與聯絡方式。（資料控制者＝「對客戶資料負責的人」。個人版就是你本人，不是系統廠商。）
  5. 逐項勾選「開通確認」：共 4 項，每一項讀完再勾。每次勾選都會留下紀錄（誰、哪一版文字、什麼時間）。
  6. 按完成設定。

完成後你會看到頁面變成「我的業務資料」，顯示你的姓名、職業別、所屬公司、資料控制者，以及「手機 LINE 工作台」的綁定狀態；此時還會出現一組綁定連結（下一節要用）。
這一步不能請別人代按

開通確認是你本人的聲明，必須用你自己的帳號登入後台勾選。客服用「代登入」只能看，不能替你勾。

之後要改資料

回到同一頁按修改。送出時需要再勾一次開通確認。

2-4　看一下「模組設定」

在哪裡保險業務 → 資料與設定 → 模組設定

這一頁是整個保險模組的總設定。新手先看懂這幾項就好，其他都用預設值，不用改：

再往下捲，還有客戶分級名稱（A、B、C、D 級你想怎麼叫都可以）、健康字詞清單、保障缺口規則（算保障缺口用的倍數與金額）、AI 讀保單首頁的每月上限。

小提醒

如果「資料控制者」是空的，系統會擋住「新增客戶、補登同意、匯入」，並提醒你先來這裡填。系統不會拿別人的名稱頂替你。

3

綁定手機工作台

把你的 LINE 和你的業務身分接在一起。綁好之後，手機 LINE 就能當「業務工作台」，每天的早報也是送到這個 LINE。

在哪裡後台「我的業務資料」→ 傳連結到自己的 LINE → 手機打開

  1. 在後台「我的業務資料」找到綁定連結（按產生綁定連結，連結只顯示這一次）。
  2. 按複製綁定連結，貼到你自己的 LINE（例如傳給「我的記事本」或自己的官方帳號聊天室）。
  3. 用手機 LINE 點開這個連結。若跳出「使用 LINE 登入」，照指示確認。
  4. 看到「綁定業務身分」畫面，確認名字是你，按綠色的確認綁定。
  5. 綁定完成後按前往業務工作台，並把它釘選在聊天室，以後直接從那裡打開。

不要轉傳給別人。過期或失敗了，回後台重新「產生綁定連結」，舊的就會失效。

一定要先加官方帳號好友

早報等通知，是「你的官方帳號」傳到「你的 LINE」。請確認你本人的 LINE 已加你自己的官方帳號為好友，否則收不到。

4

建立第一個家庭與客戶

保客+ 以「家庭」為單位管理客戶：一家人放在同一個家庭，成員一人一筆。先建家庭，再加家人。

4-1　用手機建立家庭

在哪裡手機 LINE 業務工作台 → 底部「我的家庭」→ 新增家庭

  1. 點底部我的家庭，再按綠色的新增家庭。
  2. 填家庭名稱（例：王小明一家）。分級先不用選（A 重點經營、B 定期關懷、C 一般往來、D 暫不經營，是你自己的判斷，系統不會自動算）。
  3. 備註可以寫「朋友介紹，週末方便約訪」這類內容。請勿寫病史、疾病——保客+ 不收健康資料。
  4. 按建立家庭。
完成後你會看到進入這個家庭的明細頁，上面是家庭名稱，下面有「成員」區。

4-2　加入家庭成員（最重要的一步：同意）

在哪裡家庭明細頁 → 成員 →「新增」

  1. 按成員區右上角的＋新增。
  2. 填姓名（必填）；性別、生日、手機、職業類別、年收入級距都是選填，生日建議填，系統才能提醒生日與年齡里程碑。
  3. 勾選「已向當事人說明告知事項並取得同意（必填）」，再選取得方式（書面、口頭、LINE 對話）。沒勾就不能儲存。
  4. 未成年子女或長輩，可以選由同一個家庭的成員（例如要保人）代為同意。
  5. 按儲存。
完成後你會看到成員出現在清單裡，名字旁有「已同意（第 1 版）」。沒有 LINE 的家人（小孩、長輩）也一樣可以建，只是不能傳 LINE 給他們。
為什麼一定要同意？

客戶資料受個人資料保護法規範，你要先把「告知事項」向對方說明並取得同意。個人版你本人就是資料控制者，責任在你。畫面上的「看告知事項全文」可以點開來讀，說明時照著唸即可。

家庭關係

在家庭明細最下面的「家庭關係」按新增，可記配偶、子女、父母、兄弟姊妹。一對人只記一筆。建好關係，系統才能在「今天」頁提醒你「新增配偶關係，可約談家庭保障」這類建議。

4-3　已經有 Excel 名單？用匯入，一次建好

在哪裡後台：保險業務 → 資料與設定 → 匯入客戶與保單

  1. 按右上角下載範本，照範本的欄位整理你的名單（Excel 另存 CSV 或直接用 .xlsx 都可以，一次最多 2000 列）。
  2. 選匯入種類「客戶」，選檔案。系統會逐列檢查，錯誤列會寫明原因且不會匯入；黃字只是提醒。
  3. 勾選「我確認已向這份名單上的每一位當事人說明告知事項並取得同意」並選取得方式。
  4. 按匯入。
完成後你會看到預覽沒有錯誤列後匯入成功，客戶依「家庭」名稱建在同一戶。
個人版要先完成 ② 的首次設定才能匯入

匯入的客戶自動由你負責。同一份檔案再匯一次，系統會提醒「這份檔案已經匯入過」，確認後才會再匯（會產生重複客戶）。

4-4　用電腦看與管理家庭

在哪裡後台：保險業務 → 客戶與規劃 → 客戶與家庭

電腦上同樣能看到所有家庭，適合整理資料、批次處理。按新增家庭可建立，點某一戶可看成員、保單與保障總表。

「刪除」是徹底刪除

客戶資料、保單、保單照片、提醒會一併刪除且無法復原；拜訪紀錄保留但去識別。刪除前請確認。

5

建立保單

把客戶的保單記進系統，之後才能算出家庭保障總表與缺口。有兩種方式：手動輸入、用手機拍保單首頁讓 AI 幫你讀。

5-1　手動新增保單

在哪裡手機工作台 → 我的家庭 → 點進家庭 →「保單」→ 新增保單（或電腦後台：客戶與家庭 → 該家庭 → 保單與保障總表）

  1. 在家庭明細按保單，進入保單清單，按右上角新增保單。
  2. 填保險公司、商品名稱、保單號碼，選險種類別（壽險、醫療、重大疾病、意外、失能、長期照顧、年金…）。
  3. 選被保險人與要保人（都必須是這個家庭的成員；家人還沒建的話先回去新增成員）。
  4. 填生效日、繳別、繳費年期、每期保費。繳費方式只記類別（信用卡、轉帳、現金），不要填卡號帳號。
  5. 往下找到保障明細，按新增一列，逐列記主約與附約：險種、名稱、保額（醫療險記「住院日額」）。家庭保障總表就是依這裡的數字算的，沒填保障明細，保單只會出現在清單。
  6. 按儲存。
完成後你會看到清單裡出現這張保單，狀態是「有效」。同一個家庭裡，同一家保險公司的同一個保單號碼只能登錄一次。
備註與受益人說明

一樣不要寫健康資料。偵測到病名、住院等字詞，系統會在送出前提醒你。

5-2　拍照讀取保單首頁（AI 幫你讀）

在哪裡新增保單頁最上方 →「拍保單首頁，讓系統幫忙讀」

  1. 按拍保單首頁，讓系統幫忙讀，用手機拍保單首頁（保單資料頁）。不要拍健康告知書。
  2. 系統讀出一份「草稿」，每一欄會標示狀態：已讀取、請核對、看不清楚未填入、格式不對未填入、首頁沒有。
  3. 逐欄核對。看不清楚的欄位不會替你亂填，請對照保單自己補。被保險人的姓名對得上家庭成員，才會自動選好。
  4. 核對無誤，按確認儲存，保單才真的建立，照片同時存進私有儲存。沒按儲存，就不會留下任何保單資料。

同一張保單的資料常分在好幾張紙上，可以按選多張一起讀，一次最多 6 張（保單首頁、附約明細表、保險存摺 App 截圖、繳費通知單），系統會合併成一份草稿，每一欄會顯示取自第幾張。

完成後你會看到出現一份可編輯的草稿；你確認儲存後，這張保單就出現在清單。
健康告知頁會被丟棄

照片裡偵測到健康告知、病歷等內容，那一張整張丟棄、不存圖、不存文字；如果全部都是健康告知頁，整批不採用。這是為了符合「系統不收健康資料」的規則。

每月有使用上限

AI 讀保單每月有次數上限（模組設定可看，填 0 就是停用），每一張照片算一次。額度用完請改用手動輸入。每次使用都會留下紀錄，但紀錄裡不含保單內容。

拍照小技巧

光線充足、對準保單、整頁拍進來、不要反光，辨識會準很多。

5-3　用電腦看保單清單

在哪裡後台：保險業務 → 客戶與規劃 → 客戶與家庭 → 點進家庭 →「保單與保障總表」

照片只有你看得到

保單照片存放在私有儲存，不會產生公開網址；點「照片」才會產生 5 分鐘有效的查看網址，每次查看都有紀錄。

6

看保障總表與缺口、產生健診報告

把一家人的保單整理成一張表，看每個人「已經有多少、建議多少、還差多少」，幫助你和客戶當面討論保障規劃。

6-1　看家庭保障總表與缺口

在哪裡手機工作台 → 家庭明細 →「保障總表」（或保單清單右上角「保障總表」）

  1. 在家庭明細按保障總表。
  2. 每位家人一個區塊：壽險、重大疾病、意外、失能、長期照顧的保額，醫療住院日額，年繳保費合計。
  3. 下方的顏色標籤是缺口：綠＝足夠，黃＝偏低，紅＝不足，旁邊寫「差多少」。
完成後你會看到一眼看出誰壽險不足、誰沒有意外險。
怎麼算的
  • 只計入「有效」與「繳清」的保單；月繳、季繳、半年繳會換算成一年的保費。
  • 外幣保單不換匯，保額不併入台幣欄位。
  • 壽險建議＝年收入 × 倍數（年收入依成員的「年收入級距」推估；沒填級距會顯示「無法判斷」，所以建客戶時填級距很有用）。
  • 18 歲以下成員，建議要有意外險。
  • 規則可在後台「模組設定 → 保障缺口規則」調整。
只談保障，不推商品

總表與缺口不會顯示任何商品名稱或推薦商品，只供當面討論。

6-2　列印成 PDF

在哪裡保障總表頁右上角 →「列印／存成 PDF」

  1. 按列印／存成 PDF。
  2. 在瀏覽器的列印視窗，印表機選「另存為 PDF」。
  3. 也可以選「列印（不含缺口）」，只印保障、不印缺口。
在 LINE 裡可能不能列印

LINE 裡打開的小網頁多半不能直接列印。請點右上角選單，選「用預設瀏覽器開啟」再列印，或改用電腦後台列印。

頁尾固定有免責文字「本表由服務人員依保單資料整理，實際權益以保險公司保單條款為準」，以及你的姓名、所屬機構與登錄字號。每次產生列印版都會留下紀錄。

6-3　保單健診報告（正式版，可給客戶簽收）

在哪裡手機工作台 → 家庭明細 →「健診報告」→ 產生報告

  1. 在家庭明細按健診報告，再按＋產生報告。
  2. 系統把「當下的保障總表與缺口」做成一份快照報告，依序編號（第 1 號、第 2 號…）。之後保單再改，已產生的報告不會變；保單有更新請重新產生。
  3. 要給客戶簽收，有兩種方式：LINE 簽收（選一位已連 LINE 的家人，系統把報告連結傳到他的 LINE，他打開看完按「確認收到」）、紙本簽收（列印給客戶簽名，再登錄簽收人與日期）。
完成後你會看到清單出現「第 1 號」報告，狀態「未簽收」；客戶簽收後會變成已簽收。
作廢不是刪除

報告不會被刪，只會標「已作廢」並記原因；作廢後不能再簽收。報告內容不含商品建議、照片、業務備註。

6-4　需求試算（退休、教育金、房貸、所得替代）

在哪裡手機工作台 → 底部「我」→ 需求試算（或家庭明細的「需求試算」）

  1. 選要算哪一種：退休金、子女教育金、房貸保障、所得替代（家庭生活保障）。
  2. 填必填欄位（例如退休金：目前年齡、退休後每月生活費）；留空的欄位會用預設假設值（例如通膨 2%、退休前報酬 4%），灰色字就是預設值。
  3. 按試算，看結果。
完成後你會看到出現「退休金試算結果」：距離退休幾年、需要的總額、缺口、每年與每月應準備的金額。
這裡的試算不會存下來

在「我」頁的試算只是計算機，不存資料。若在某個家庭底下按「存到這一戶」，也只存計算結果（缺口、每年應準備），你輸入的年收入、支出、資產、貸款不會存。試算只是規劃參考，不是商品建議。

7

每天怎麼用：「今天」頁、早報、提醒

養成每天早上打開「今天」頁的習慣：系統已經幫你整理好今天該聯絡誰、有什麼快到期。

7-1　每天早上的 LINE 早報

在哪裡每天早上，你的 LINE 會收到一則來自「你的官方帳號」的訊息

早報是系統每天替你整理的一則摘要，一人一天最多一則。預設早上 07:30 送出（可在後台「祝福與行事曆」改時間或關閉）。

早報（示意）
內容依你當天的資料，可能包含以下段落（沒有內容的段落不會出現）：
  • 今日行程
  • 今天先處理這幾位（風險燈號，紅燈在前）
  • 送件回覆期限
  • 待確認的祝福
  • 到期提醒（今天／未來 7 天／逾期）
  • 年度保單檢視、生命事件建議
  • 久未聯絡
最後附「今天」頁的連結。

示意圖：列出早報可能出現的段落，實際內容以你收到的訊息為準。

完成後你會看到點早報最後的連結，直接打開工作台「今天」頁。當天沒有任何事項，就不會推早報。
沒收到？

請看 ⑬ 常見問題「為什麼今天沒收到早報」。最常見是：沒綁定 LINE、沒加官方帳號好友、或當天早上才綁定。

7-2　「今天」頁

在哪裡手機工作台 → 底部「今天」

  1. 點底部今天。
  2. 由上往下看卡片：今天先處理這幾位（風險燈號）、送件回覆期限、到期提醒、年度保單檢視、生命事件建議。
  3. 最下面有五顆捷徑按鈕：祝福、AI 助理、經營（風險、檢視）、提醒、活動量、關懷訊息。
完成後你會看到你知道今天該先聯絡哪幾位客戶。
個人版也有「活動量」

「活動量」顯示你這一週的拜訪次數、新增家庭數、提醒完成率等，看自己的節奏。

7-3　處理提醒

在哪裡手機工作台 → 今天 → 提醒（或早報「到期提醒」旁的「去處理」）

系統會自動替你產生這些提醒：生日、年齡里程碑（滿 6、12、18、22、40、50、60、65 歲）、保單週年、繳費日、滿期，另外你可以自己新增「自訂提醒」。

  1. 點提醒，用上面的分頁切換：今天與未來 7 天、已逾期、近 30 天已處理。
  2. 每一則提醒下面有三顆按鈕：已處理（聯絡過了）、延後（選一個之後的日期，最多 90 天）、略過（這則不適用）。
  3. 想自己加一則，按＋新增自訂提醒，例如「約訪討論房貸」，要選你負責的家庭。
完成後你會看到處理完的提醒從清單消失，「近 30 天已處理」可以把它重新打開。
提醒的規則

同一件事同一年只會有一則；日期一律以台灣時間計算；處理備註也不要寫健康資料。

7-4　客戶訊息

在哪裡手機工作台 → 底部「客戶訊息」

已經連結 LINE 的客戶，在你的官方帳號傳來的訊息，會出現在這一頁，你可以直接回覆。有新訊息時，系統也會推一則通知到你的 LINE（只寫「客戶 ○○○ 傳來新訊息」，不含內容，點連結來看）。同一位客戶 30 分鐘內最多通知一次，晚上 10 點到早上 7 點不推播。

回覆內容有健康字詞會被擋下

回覆客戶時，若含病名、住院、體檢等字詞，系統會直接擋下、沒有「仍要送出」，請改用不含健康內容的說法，或改用電話聯絡。含「保證、穩賺、最高」這類字句則是先提醒（見 ⑪、⑫ 的合規副駕）。

8

祝福與關懷訊息

系統幫你記住每位客戶的生日、節日、紀念日，時間到了從你的官方帳號送出祝福；關懷訊息則是你用範本主動關心客戶。

8-1　祝福怎麼運作（先看懂流程）

在哪裡流程說明

  1. 系統產生草稿：每小時檢查一次，替「今天到未來 3 天」的每個場合（生日、農曆生日、節日、紀念日、保單週年、繳費提醒）產生祝福草稿。只有「已連 LINE」的客戶才會產生。
  2. 你確認：預設是「早上一鍵確認」——你在工作台「祝福」頁預覽、可以改字，按「確認」或「全部確認」。沒確認就不會發。也可以改成「自動發送」，時間到就發。
  3. 發送：當天預設 09:00（台灣時間）從你的官方帳號發出，訊息最後自動附「姓名（所屬公司）」。

同一個場合同一年只會有一則，重跑、重啟都不會重發。

客戶沒連 LINE 就沒有祝福

祝福草稿只替「已連結 LINE 的客戶」產生。要先請客戶連結（見 ⑬ 或工作台家庭明細的「LINE 連結」），才會開始收到祝福。

8-2　選擇你要的模式

在哪裡手機工作台 → 今天 → 祝福 → 上方「我的模式」

  1. 點祝福，再切到我的模式分頁。
  2. 「預設模式」選早上一鍵確認（建議新手）或自動發送。
  3. 底下每個類別（生日、農曆生日、節日、保單週年、繳費提醒…）可以單獨設：跟預設、早上一鍵確認、自動發送。例如「節日自動發、生日自己看過再發」。
  4. 按儲存。
完成後你會看到之後系統產生草稿，會依你的設定處理。「待發送」分頁會列出等你確認的祝福。
改字與健康字詞

你可以修改祝福草稿的文字；若出現健康相關字詞，系統會直接擋下（沒有「仍要送出」）。AI 寫的祝福一律要你確認，不會自動發。

8-3　設定客戶的農曆生日與紀念日

在哪裡家庭明細 → 成員旁的「祝福與紀念日」

  1. 在成員旁按祝福與紀念日。
  2. 稱呼：祝福裡怎麼叫他（例：王大哥、林媽媽；空白就用姓名）。
  3. 農曆生日：可以從國曆生日換算帶入。有農曆生日的客戶，預設只發農曆生日；想兩種都發，勾「國曆生日也發祝福」。
  4. 紀念日：按＋新增，加結婚紀念日、開業日、成交紀念日等，可選國曆或農曆、每年重複或只一次。
  5. 若這位客戶不想收祝福，勾「不要發祝福給這位客戶」。
完成後你會看到到了日子，系統會自動排祝福。

8-4　後台的祝福設定（發送時間、節日、範本）

在哪裡後台：保險業務 → 關懷 → 祝福與行事曆

頁面上方有四個分頁：設定、節日、範本、發送紀錄。

  • 節日分頁：內建 20 個台灣節日（國曆 11 個、農曆 9 個），預設開啟元旦、春節、情人節、元宵、母親節、端午、七夕、父親節、中秋、重陽、聖誕，其他可自行開關，也能新增自訂節日。
  • 範本分頁：依職業別內建祝福範本，不含任何商品、報酬率、優惠字眼。個人版建立就能用，不需要核可；可以「複製」成自己的再修改。範本裡不要寫你的姓名，簽名檔由系統自動附。可用欄位：{稱呼}、{節日}、{客戶姓名}、{繳費日}、{滿期日}、{紀念日名稱}。
  • 發送紀錄：看送出的結果。「客戶有互動」代表他按了回覆按鈕或回話；LINE 不提供「有沒有讀」，所以不會顯示已讀。
不會發的情況

對方封鎖或刪除好友（未送：非好友）、客戶沒有連 LINE（未送：沒有 LINE）、客戶在行銷黑名單、你勾了不要發祝福、當天沒確認（未確認，未發送）。

8-5　關懷訊息（用範本主動關心客戶）

在哪裡手機工作台 → 今天 → 關懷訊息；範本在後台：保險業務 → 關懷 → 關懷訊息

關懷訊息只能發範本，不能自己打字群發。個人版範本建立後直接可用；安裝時附的範本是草稿，在後台「關懷訊息」按啟用就能用。

  1. 在手機工作台「關懷訊息」頁，1. 選範本。
  2. 2. 選客戶：只列出你負責的客戶，沒連結 LINE 的不能勾。
  3. 看預覽，按發送。
完成後你會看到發送結果與原因（例如：不是好友、暫時無法確認）寫在結果頁與「發送紀錄」。
每日上限與規則

預設每天最多發 50 則；這次要發的則數超過當天剩餘額度，整批不送。「關懷」類範本會檢查客戶是否在黑名單或已停用；「服務通知」（例如繳費提醒）不做這一項，但仍必須是好友。範本不得含特定商品名稱、報酬率或優惠（保險業務員管理規則第 19 條）。

9

約訪、拜訪紀錄、行事曆與手機日曆訂閱

安排與記錄你和客戶的見面，並把行事曆同步到手機的日曆 App。

9-1　排約訪

在哪裡家庭明細 → 成員旁「祝福與紀念日」→ 排約訪 →「新增約訪」

約訪要綁定客戶，所以要從客戶的「祝福與紀念日」頁新增。填日期、時間、標題（例：家庭保障檢視）後儲存，就會出現在行事曆。

9-2　看行事曆

在哪裡手機工作台 → 底部「行事曆」

  1. 點底部行事曆。
  2. 上方切換日、週、月三種檢視。
  3. 內容包括你的待辦、約訪，以及要發的祝福、保單提醒（生日、繳費日、保單週年）。
  4. 待辦與約訪下面有完成、延後一天、刪除。下方有新增待辦與久未聯絡。
待辦的標題、地點、備註不能寫健康資料

因為行事曆會同步到手機日曆，比一般備註更容易外流，所以寫到健康字詞會被擋下。

久未聯絡

系統依家庭分級的天數（預設 A 級 30 天、B 級 60 天、C 級 90 天、D 級不提醒）列出太久沒聯絡的家庭，可在後台「祝福與行事曆 → 設定」改天數。

9-3　記一筆拜訪紀錄

在哪裡家庭明細最上方 →「記一筆拜訪」（或「今天 → 活動量」）

  1. 按記一筆拜訪。
  2. 選對象（整個家庭或其中一位成員）、日期、類型（約訪、面談、電話、送件、理賠協助、關懷）。
  3. 填結果（請勿填寫健康資料），需要的話寫下次行動與日期。
  4. 按儲存。
完成後你會看到拜訪會記進這位客戶的歷程，也會累計進你的活動量。

客戶歷程：一條時間軸看完所有往來

在哪裡家庭明細 → 成員旁的「客戶歷程」

每位客戶一條時間軸：LINE 對話、拜訪、筆記、提醒處理、保單異動、送出的祝福與關懷訊息、理賠與送件紀錄，新的在上面。按寫筆記可以加手寫筆記（也不收健康資料）。

9-5　把行事曆同步到手機日曆（iCal 訂閱）

在哪裡手機工作台 → 行事曆 →「同步到手機行事曆」

iCal 訂閱的意思是：你拿到一條「私密網址」，把它貼到手機（或 Google 日曆）的「訂閱行事曆」裡，你的約訪、待辦和祝福就會自動顯示在手機日曆。

  1. 在工作台「行事曆」最下方按同步到手機行事曆，再按產生連結。
  2. 網址只顯示這一次，請馬上按複製。
  3. iPhone：設定 → 日曆 → 帳號 → 新增帳號 → 其他 → 加入已訂閱的行事曆，貼上網址。
  4. Google 日曆（電腦網頁版）：左邊「其他日曆」旁的＋ → 以網址新增，貼上網址。
這條網址等於「你的行事曆鑰匙」

不要貼到公開地方。遺失或外流，就按重新產生，舊網址立刻失效；或按停用這條連結。

單向、會有延遲

只能「系統 → 手機」單向同步，在手機日曆裡改的東西不會回到系統。Google 日曆多久重新讀一次由 Google 決定，可能延遲數小時，不是壞掉。

10

數位名片與潛客

「潛客」是還不是客戶的人（交換名片、朋友介紹、活動認識）。「數位名片」是一頁你的線上介紹，可以用 LINE 傳給朋友。

10-1　編輯並公開你的數位名片

在哪裡手機工作台 → 底部「我」→「我的名片」

  1. 點我的名片，按修改內容。
  2. 上傳照片（系統會重新壓縮並去掉拍攝地點等資訊）。
  3. 填一句話介紹、服務區域、自我介紹、聯絡電話、Email。姓名、所屬公司、登錄字號取自你的業務資料，名片上一定會標示所屬公司。
  4. 送出。個人版送出即公開。公開後，按分享名片，就能用 LINE 傳給朋友。
名片屬於文宣，有些字會被擋

「保證、穩賺、保本、最高、唯一、報酬率、退佣、保費折扣、優惠、限時」這類字，系統會直接擋下。被擋下的字詞清單在後台「轉介紹」頁的設定卡片可以看。沒填所屬公司的人不能公開名片，請先在「我的業務資料」補上。

完成後你會看到名片有一個不需登入就能看的公開頁，只顯示名片欄位，不會出現任何客戶資料。

10-2　管理潛客、拍名片、轉成客戶

在哪裡手機：我 → 名片與潛客；電腦：保險業務 → 客戶開發 → 名片與潛客

  1. 按拍名片或新增潛客，拍一張名片照片。系統先建一筆「名片待確認」的潛客，照片存進私有儲存。
  2. 若名片辨識已開通，畫面會預填姓名、公司、職稱、電話等，標「請確認」的是低信心欄位；辨識結果不會自動寫入，要你確認或修改後按儲存。沒開通辨識也可以手動填。
  3. 潛客狀態：新名單、聯絡中、不再追蹤；成為客戶後是「已轉客戶」。
  4. 要成為客戶時，在潛客明細按轉成客戶：系統建一個家庭與一位成員（帶入姓名與手機）。一定要勾「已取得當事人同意」並選取得方式，沒勾不能轉。
只帶姓名與手機

公司、職稱、地址、備註不會自動變成客戶資料，需要的話到家庭明細補。名片還沒確認前不能轉。

合規提醒：保護客戶，也保護你

保險是高度受管制的行業。保客+ 把幾件法律上要做的事做進系統：告知與同意、不收健康資料、訊息措辭提醒、刪除與匯出紀錄。

11-1　你要記住的三件事

在哪裡三大原則

  1. 先同意，再建檔：新增客戶前，先向對方說明告知事項並取得同意（書面、口頭或 LINE 對話都可以，但要選對方式）。
  2. 不收健康資料：病歷、病名、體檢屬於個資法的特種個資，原則上不得蒐集。備註、拜訪結果、待辦、訊息裡出現病名、住院、手術等字詞，系統會提醒或擋下。
  3. 訊息不要承諾報酬、不要談特定商品與優惠：依保險業務員管理規則第 19 條，對外訊息要標示所屬公司，不得誇大不實，不得以折減保費或其他不當利益招攬。

11-2　發送前檢查（合規副駕）

在哪裡手機工作台 → 今天 → AI 助理 → 發送前檢查

  1. 把準備傳給客戶的文字貼進輸入框。
  2. 按檢查。
  3. 系統列出命中的字詞、原因，與建議文字；你可以改用建議文字，或選「仍用原文（複製）」。
完成後你會看到在「客戶訊息」回覆客戶時，按送出前也會自動先跑一次同樣的檢查。
只提醒，不代替公司核可

合規副駕只是提醒（健康字詞才會直接擋下），沒被標出來的內容不代表一定合規，最後仍要依所屬公司規定把關。

11-3　後台合規紀錄

在哪裡後台：保險業務 → 合規與品質 → 合規紀錄

  • 告知事項：每一次用來取得同意的全文都存成一個版本，存了就不能改、不能刪，能查「這位客戶當初同意的是哪一段文字」。你的姓名、聯絡方式或職業別一改，系統自動存成新版，已同意舊版的客戶會變成「需重新同意」，向客戶說明後按「補登同意」即可。
  • 刪除：在「客戶與家庭」按刪除，會真的刪除客戶資料、保單、照片、提醒與傳給他的訊息全文，無法復原；拜訪紀錄保留但去識別。刪除原因欄不要填姓名。
  • 匯出：客戶要求索取資料副本時，在成員旁按「匯出資料」。每次匯出都有紀錄。
資料備份

資料庫備份依既有週期輪替，刪除後的資料最長約 30 天內仍存在於加密備份中，之後自然消失。

告知文字請覆核

系統內建的告知事項範本僅供參考，正式使用前請所屬公司法遵或律師覆核。

12

AI 助理

AI 幫你整理「今天該聯絡誰」、起草祝福、整理面談重點。但記得：AI 只產生草稿，一律由你確認才生效。

在哪裡手機工作台 → 今天 → AI 助理

  1. 今天該聯絡的客戶：系統依生日、保單週年、滿期、停效、到期提醒、送件期限、久未聯絡列出（不花額度）。按重新產生 AI 早報，會替每位客戶加一句「為什麼今天該聯絡他」和一段問候開場白草稿；開場白要自己確認後複製傳送。
  2. 跟助理說話（輸入框）：「查王小明」看客戶摘要；「記：王小明想了解退休規劃」建立筆記草稿；「下週二下午三點約王小明」建立約訪草稿，按確認才存。看不懂的話助理會回「看不懂」，不會亂做。
  3. 祝福／面談整理：選客戶與場合產生祝福草稿；或打字整理面談重點，確認後存成筆記與待辦。
完成後你會看到草稿標示「AI 草稿」，你確認、修改或忽略都會留下紀錄。
AI 的安全規則
  • 助理只在你負責的客戶範圍內查詢，不能刪除資料，也不能直接傳訊息給客戶。
  • 送給 AI 的內容會先去識別（姓名、地址、保單號碼等換成代號），含健康字詞的內容不會送出。
  • 助理不提供商品推薦或投資建議，要求推薦會直接拒答。
  • 每位業務每天有額度，用完會顯示「今天的助理額度用完了」，規則式功能照常可用。
語音面談整理

預設是關閉的（錄音會送雲端 AI 服務轉文字，轉完即丟）。需要在後台「AI 助理與品質」由你本人確認後才能開啟，新手先不用。

後台：AI 助理與品質

在哪裡後台：保險業務 → 合規與品質 → AI 助理與品質

這裡看用量與合規字詞統計；「助理設定」可調每月上限與每日額度，「合規字詞」可加入公司特定的商品名稱，讓發送前檢查也提醒。

常見問題

遇到狀況先在這裡找。點問題就會展開答案。

為什麼今天沒收到早報？

先看工作台「提醒」頁最上方，系統會寫出沒送出的原因。常見狀況：

畫面說明怎麼處理
沒有綁定 LINE，無法發送回 ③，用「我的業務資料」產生綁定連結，在手機綁定。注意：早報當天早上若還沒綁好，當天不會補發，要等隔天。
未加入官方帳號好友（或已封鎖）用綁定的那個 LINE，加你自己的官方帳號為好友。
這個 LINE 在黑名單中到後台「會員管理」解除黑名單。
LINE 官方帳號已更換，請重新綁定換過官方帳號後，要重新綁定一次。
暫時無法確認是否為好友，稍後會再試系統當天稍後會自動再試（最多 3 次），不用處理。

另外也要確認：早報時間（預設 07:30，後台「祝福與行事曆 → 設定」可改，也可能被關掉）；當天真的沒有任何事項就不會推；一人一天最多一則。

為什麼祝福「待發送」是空的？
  • 祝福草稿只替「已連結 LINE」的客戶產生。客戶還沒連 LINE，就不會有草稿。
  • 系統只產生「今天到未來 3 天」（預設）的草稿；最近幾天沒有生日、節日、紀念日，就是空的。
  • 有農曆生日的客戶，預設只發農曆生日。
  • 節日預設只開 11 個，其他要到後台「祝福與行事曆 → 節日」開啟。
  • 客戶勾了「不要發祝福」，或對方封鎖好友、在黑名單，也不會有。

也可以用「關懷訊息」頁，先確認範本與預覽看起來對不對。

名片、理賠、轉介紹、送件的時間，為什麼和實際差 8 小時？

這是已知問題：手機工作台少數頁面（名片、理賠協助、轉介紹、送件進度）顯示的「日期時間」會比實際少 8 小時（時區顯示的差異）。資料本身是對的、不影響提醒與發送，請以實際時間為準，日期欄位則沒有影響。

打開工作台一直轉圈圈「讀取中…」

第一次打開或網路較慢時，會停留幾秒到十幾秒。等一下，或關掉再從聊天室釘選的連結重新打開。如果一直停在「需要先用 LINE 登入」，照畫面指示登入即可。

新增客戶時出現「請先設定資料控制者」或不能儲存

個人版要先完成 ② 的首次設定（含開通確認），資料控制者不能是空的；客戶同意那一格也要勾。請回 ② 完成後再試。

輸入備註時被擋下，說「本系統不收健康資料」

備註、拜訪結果、待辦、回覆客戶的訊息裡出現病名、住院、手術、體檢等字詞，系統會提醒或直接擋下。請改成不含健康內容的說法（例如「想加強保障」），或改用電話溝通。送給客戶的訊息，沒有「仍要送出」可按。

在 LINE 裡按「列印」沒有反應

LINE 內建瀏覽器多半不能列印。點右上角選單，選「用預設瀏覽器開啟」再列印；或用電腦後台列印。

客戶要怎麼連結他的 LINE？

在家庭明細，點客戶旁的LINE 連結，系統產生一條連結，傳給客戶本人。連結 72 小時有效、只能用一次。客戶打開、閱讀並同意個資告知事項後，就連上了；之後這位客戶才會有祝福、能收到關懷訊息。一個 LINE 只能連一位客戶。

AI 讀保單讀錯、讀不出來

AI 讀出來的是草稿，請逐欄核對。看不清楚的欄位不會預填。可以重拍（光線、整頁、不反光），或改用手動輸入。每月有次數上限，用完請手動輸入。

手機日曆訂閱後，新增的行程多久才出現？

是單向同步，且重新讀取的頻率由 Google 或 iPhone 決定，可能延遲數小時，不是壞掉。不需要即時看的話，以工作台的行事曆為準。

我想換電腦、忘記後台密碼

忘記後台密碼，請聯絡講師或客服協助重設。換電腦不影響資料，用同一組帳號密碼登入即可。

資料會不會被別人看到？

個人版的客戶資料只屬於你的租戶，其他學員看不到。保單照片存放在私有儲存，不產生公開網址。客服「代登入」協助時，只能查看與做一般操作，需要你本人表示意思的動作（例如勾選同意、開通確認）一律不能代做。
