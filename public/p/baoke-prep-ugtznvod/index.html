課前要準備什麼

  1. 一台電腦（建議用 Chrome 瀏覽器）。手機也能做，但 LINE Developers 網站在電腦上比較好操作。
  2. 手機上的 LINE，而且知道自己 LINE 綁定的 Email 與密碼。登入 LINE 後台時，手機會跳出驗證碼要你確認。
  3. 一個常用的 Email，用來收 LINE 的通知與驗證信。
  4. 想好官方帳號的名稱：客戶加好友後在聊天室看到的就是這個名字，最多 20 個字。建議「姓名＋身分」，例如「王小明｜保險顧問」或「王小明 保險理財服務」。
  5. 講師寄給你的保客+ 後台帳號（與你的「專屬網址代號」）。還沒收到也可以先做第 1～5 節。

這份講義課前只做到「建好、找到」。官方帳號、Messaging API、LINE Login channel 建好，並知道每組資料放在哪裡就好。不用把任何金鑰抄下來或傳給別人，課堂上你會自己登入後台貼上。

全程用同一個 LINE 帳號登入。申請官方帳號、LINE Developers、之後每次管理，都用你自己長期在用的那個 LINE 帳號。換帳號登入會看不到自己建的東西。

1

申請 LINE 官方帳號

約 5 分鐘

網址：https://tw.linebiz.com/account/（LINE 台灣官方「免費開設帳號」頁）

  1. 打開上面的網址，按右上角綠色的 免費開設帳號。
  2. 登入畫面選 LINE帳號，用手機 LINE 掃碼或輸入 LINE 的 Email／密碼登入。
  3. 進入「建立LINE官方帳號」表單，依序填：
    • 帳號名稱：第 0 節想好的名字（之後可以改，但每次改名要等一段時間才能再改）。
    • 電子郵件帳號：會自動帶入，確認是你常用的信箱。
    • 公司所在國家或地區：台灣。
    • 公司名稱：可不填；要填就填所屬通訊處或個人工作室名稱。
    • 業種：大分類選「銀行、保險、金融」，小分類選最接近的「保險」相關項目。
  4. 看過服務條款後按 確定，下一頁確認內容再送出，看到「申請完成」就完成了。

要不要申請「認證帳號」（藍色盾牌）？不需要。一般帳號就能使用保客+ 的所有串接功能。認證要審核、時間不一定，可以之後再決定。

方案：預設是免費的「輕用量」方案，每月可主動發送的訊息則數有上限（以 LINE 官方公告為準）。上課前不需要升級。

已經有自己的官方帳號？可以直接用，不必重新申請，跳到第 2 節。但如果那個帳號是前公司或廠商幫你開的，請先看第 8 節的「已經有官方帳號」那一題。

2

基本設定：回應設定

約 3 分鐘

網址：https://manager.line.biz/（LINE Official Account Manager，以下簡稱「官方帳號後台」）

保客+ 會替你自動回覆、發生日祝福與提醒。LINE 內建的「自動回應訊息」和「加入好友的歡迎訊息」如果開著，客戶會同時收到兩套訊息，所以要關掉。

  1. 登入官方帳號後台，在「帳號一覽」點你剛建的帳號。
  2. 右上角按 設定，左側選 回應設定。
  3. 加入好友的歡迎訊息：切成關閉（改由保客+ 發）。
  4. 自動回應訊息：切成關閉。
  5. Webhook：課前先不用動。網址課堂上由系統自動設定，你只要在 LINE Developers 把「Use webhook」打開（第 4 節說明）。
  6. 聊天：可以保持開啟，方便你用手機「LINE 官方帳號」App 手動回覆客戶。
3

開啟 Messaging API

約 5 分鐘

Messaging API 是讓保客+ 能替你的官方帳號收發訊息的「接口」。從 2024 年 9 月起，這個接口只能從官方帳號後台開，不能直接在 LINE Developers 網站建立。

  1. 官方帳號後台 → 設定 → 左側 Messaging API。
  2. 按 啟用Messaging API。
  3. 第一次使用會請你登錄「開發者資訊」：填本人姓名與 Email，同意條款。
  4. 選擇提供者（Provider）：選「建立新的提供者」，名稱建議用「你的姓名＋保險服務」，例如「王小明保險服務」。客戶在 LINE 登入授權畫面上會看到這個名稱。
  5. 隱私權政策、服務條款網址可以先空白，按 確定。
  6. 畫面狀態變成「使用中」，下方出現 Channel ID 與 Channel secret，就完成了。

Provider 選了就不能改。一定要選「你自己的、新建的」Provider，不要選公司、前東家或任何廠商的 Provider。之後第 5 節的 LINE Login channel 也必須建在同一個 Provider 底下，否則系統會認不出同一位客戶。

4

LINE Developers：找到 Channel secret、發 Access token

約 5 分鐘

網址：https://developers.line.biz/console/（畫面是英文，以下標出每個按鈕的英文名稱）

  1. 用同一個 LINE 帳號登入 LINE Developers。
  2. 左側 Providers 點第 3 節建立的 Provider，會看到一張「Messaging API」卡片，點進去。
  3. Basic settings 分頁：最上面是 Channel ID，往下捲是 Channel secret。知道位置就好。
  4. 切到 Messaging API 分頁，捲到最下面 Channel access token (long-lived)，按 Issue，產生一串很長的 token。
  5. 同一頁「LINE Official Account features」區：確認 Auto-reply messages 與 Greeting messages 顯示 Disabled。若還是 Enabled，按右邊 Edit 回到官方帳號後台關掉（第 2 節）。

Channel secret 旁邊的「Issue」不要按。那顆是「重新產生 secret」，按下去舊的就失效，串好的系統會全部收不到訊息。

Access token 只要發一次。課前發好即可，之後不要重發；重發後要重新貼進保客+ 後台。

5

建立 LINE Login channel（同一個 Provider）

約 8 分鐘

LINE Login 讓客戶在手機上打開「我的保單」等頁面時，用 LINE 身分自動登入，不用另外記帳號密碼。

  1. 回到 Provider 頁（第 4 節那張 Messaging API 卡片的同一頁），按 Create a new channel。
  2. channel 類型選 LINE Login。
  3. 填表：
    • Provider：確認是你自己的 Provider（和 Messaging API 同一個）。
    • Region to provide the service：預設是 Japan，一定要改成 Taiwan。
    • Company or owner's country or region：Taiwan。
    • Channel name：例如「王小明保險服務」（最多 20 字，不能用表情符號）。客戶登入時會看到。
    • Channel description：例如「王小明的客戶服務與保單查詢」。
    • App types：勾 Web app。
    • Email address：你的 Email。
    • 勾選同意 LINE Developers Agreement，按 Create。
  4. 建好後，在 Basic settings 往下找 Linked LINE Official Account → Edit → 選你的官方帳號 → 儲存。
  5. 如果你已經收到講師給的專屬網址代號：切到 LINE Login 分頁 → Callback URL → Edit，填 https://你的代號.ugomkcrm.com/（最後的斜線不能少）。還沒收到就課堂再填。
  6. 發布 channel：channel 名稱旁邊的狀態若顯示 Developing，點它並選 Publish，變成 Published。
  7. 切到 LIFF 分頁，把 shareTargetPicker 開關打開並同意條款（分享電子名片要用）。

沒有改成 Published，只有你自己能登入。你自己測試一切正常，客戶點開卻會看到「400 Bad Request」。這是最常見、也最難察覺的錯誤。

6

LIFF：課堂上系統自動建立，課前不必做

課前 0 分鐘

LIFF 是「在 LINE 裡打開的網頁」，客戶的「我的保單」、你的業務工作台都是靠它開啟。以前要自己手動填網址、勾選項；現在課堂上把 LINE Login 的兩項資料貼進保客+ 後台，按「自動建立 LIFF」，系統就會用正確的設定建好，並把 LIFF ID 自動存回去。所以這一節課前什麼都不用做，LIFF 的專屬網址也不用自己組。

課堂上你還要自己動手的只有幾件事（LINE 沒有開放讓系統代做）：在 LIFF 分頁打開 shareTargetPicker、在 Login channel 連結官方帳號（Linked LINE Official Account）、確認 channel 的 Region 是 Taiwan、把 Login channel 改成 Published（第 5 節已教過，課前做完最好）。「自動建立 LIFF」後畫面會逐項列出還缺哪些。

備案：自動建立失敗時，才需要手動建 LIFF（點開看做法）

通常是 Login 的 Channel ID／Secret 貼錯，或 LINE 暫時連不上。先回頭檢查那兩項再按一次；仍失敗就照下面手動建立，建好後把 LIFF ID 貼進後台。建立時要填你專屬的網址，所以收到講師給的專屬網址代號才做。

  1. LINE Login channel → LIFF 分頁 → Add。
  2. LIFF app name：例如「保客+」。
  3. Size：選 Full。
  4. Endpoint URL：https://你的代號.ugomkcrm.com/lindex（結尾是 /lindex）。
  5. Scopes：三個都勾：openid、profile、chat_message.write（客戶從保單頁轉真人客服要用）。
  6. Add friend option：選 On (Aggressive)，客戶登入時會一併提示加你為好友（需先連結官方帳號才選得到）。
  7. Scan QR：維持關閉。按 Add。
  8. 建好後，LIFF 列表會出現 LIFF ID（格式是「Login Channel ID-一串英數字」），貼進保客+ 後台的 LIFF ID 欄。

畫面上方有一段英文說 LIFF 將整合進「LINE MINI App」。台灣一般帳號照常使用 LIFF，照這份講義建立即可。

8

常見問題與卡關處理

選錯 Provider，或 Login channel 建到別的 Provider 了怎麼辦？
Messaging API 的 Provider 一旦選定不能改。如果只是 Login channel 建錯地方，到正確的 Provider 底下重建一個即可，建錯的那個先不要刪，課堂告訴講師。如果連 Messaging API 都選錯了，請先聯絡講師，不要自己重開官方帳號。
Linked LINE Official Account 的選單裡找不到我的官方帳號？
代表 Login channel 和官方帳號不在同一個 Provider，或你登入的不是建官方帳號的那個 LINE 帳號。回 Provider 頁確認兩張卡片在同一頁。
我已經有在經營的官方帳號，可以直接用嗎？
可以，好友會全部保留。先到官方帳號後台 → 設定 → Messaging API 看狀態：還沒啟用就照第 3 節做；已經是「使用中」，請確認它的 Provider 是你自己的（到 LINE Developers 看得到且你是 Admin）。若是前公司或廠商的 Provider，請先聯絡講師討論。另外，在串接之前就加好友的舊客人，要等他們再傳一則訊息給你，才會出現在保客+ 客戶名單裡，這是正常的。
我自己點開都正常，客戶點開卻出現「400 Bad Request」？
LINE Login channel 還在 Developing。到 channel 頁首把狀態改成 Published。測試時請用另一支不是你的 LINE（例如家人的）點一次，才看得出來。
Access token 的 Issue 按了沒反應，或畫面一直轉？
重新整理頁面再按一次。按鈕在頁面最下方，要捲到底才看得到。發過一次就會顯示 token，之後不需要再按。
不小心按了 Channel secret 旁邊的 Issue？
secret 會換成新的，舊的立即失效。課前還沒串接的話沒關係，課堂用新的那組即可；已經串好的話，要把新的 secret 重新貼進保客+ 後台。
LINE Developers 是英文看不懂？
網站目前只有英文與日文。照講義裡標的英文按鈕名稱找即可，右上角地球圖示可以切語言，但沒有中文。
收不到 LINE 寄的驗證信？
先看垃圾郵件匣；公司信箱有時會擋，可以改用個人 Gmail。
要不要付費、要不要申請認證帳號？
都不用。免費方案與一般帳號就能完成串接。
Webhook 燈號是黃燈或紅燈怎麼辦？
先看畫面上那一行字：
「Use webhook 開關目前是關閉的」：到 LINE Developers → Messaging API 分頁，把 Use webhook 打開，回後台按「檢查 Webhook」。這個開關只能本人點，系統無法代按。
「目前指向其他網址」：這個官方帳號原本接著別的系統，系統不會自動覆蓋；確定要改用保客+ 才按「改成本系統網址」。
「LINE 測試送到本系統失敗（HTTP 401）」：多半是 Channel secret 貼錯，重新複製貼上再存。
灰色「Webhook 狀態未能確認」：當下連不上 LINE，不是你設錯，稍後再按「檢查 Webhook」。
Webhook 沒過不影響金鑰已經存好，處理完再檢查一次即可。
「自動建立 LIFF」失敗，或提示 Add friend option 沒設上？
先確認 Login 的 Channel ID、Secret 沒貼錯。Add friend option 設不上，通常是還沒在 Login channel 連結官方帳號（Linked LINE Official Account），連結好再按一次「自動建立／校正 LIFF」。還是失敗就用第 6 節的手動做法，並告訴講師。
「同一個 Provider 檢查」顯示紅燈「查不到」怎麼辦？
先確認測試的那支手機真的已經加官方帳號為好友，再按一次。確定已加好友還是查不到，代表 Login channel 與 Messaging API 不在同一個 Provider：到 Messaging API 所在的 Provider 底下重建 LINE Login channel，並告訴講師。黃燈「還沒收到 LIFF 登入」是手機還沒登入完成；手機若看到 400 錯誤，就是 Login 還在 Developing，要改成 Published。檢查請用不是 LINE Developers 管理員的帳號（例如夥伴的手機），這樣也同時驗到 Published。
網站上的「Delete」可以按嗎？
不要按。刪掉 channel 後無法復原，客戶要重新加好友、重新登入。
9

安全提醒（必讀）

Channel secret、Access token 就跟帳號密碼一樣。拿到的人可以用你的官方帳號名義，對你所有客戶發訊息。

  • 不要貼到 LINE 群組（包括課程群組、通訊處群組）、私訊、Email、簡訊或任何雲端筆記。
  • 不要截圖傳給別人，也不要拍照留存。講師與工作人員不會跟你要這些金鑰；有人跟你要，請直接拒絕並告訴講師。
  • 課堂上由你本人登入保客+ 後台，在「系統設定 → LINE 參數」自己貼上。存進去之後只會以遮罩顯示。
  • 課堂結束後關閉瀏覽器分頁；用公用電腦的話記得登出 LINE 與保客+ 後台。
  • 懷疑外洩：到 LINE Developers 重新發行（Channel secret 的 Issue、Access token 的 Reissue），再把新的貼回保客+ 後台，並告訴講師。
  • 保客+ 後台的密碼也請勿與他人共用。
