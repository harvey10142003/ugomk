2-1建一個商品（含規格、售價、成本、條碼）
在哪裡
零售 POS → 商品管理 /dashboard/modules/pos-retail/products → 右上「新增商品」
按什麼
  1. 基本資料：名稱（必填）、分類、品牌、單位（預設「個」，水族可改支 / 包 / 罐 / 尾）、圖片、描述、標籤、上架中
  2. 變體（SKU）：規格名稱 / SKU（必填，可自動產生）/ 條碼 / 售價 / 成本 / 庫存 / 安全庫存
  3. 沒有廠商條碼：按該列「產生店內條碼」，依店家設定格式自動產一組，預設是 EAN-13 店內碼、以數字 2 開頭（國際保留前綴，保證不撞廠商條碼）
  4. 要一次建很多規格：用「批量產生變體（笛卡兒積）」
  5. 存檔：新增時按「建立商品」，編輯時按「更新商品」
會看到
列表該列顯示商品、分類、變體數、總庫存、狀態；操作欄有調整庫存 / 編輯 / 下架 / 條碼標籤。
沒看到
跳「條碼重複」= 條碼有唯一性。按「產生變體」後原規格不見 = 預期行為，批量產生會清空重建（已存檔的規格按「更新商品」時會被一併停用，庫存與歷史訂單保留），編輯既有商品時不要按。列表出現小字「本通路可售 · 另有全通路合計」= 中央帳有對應品項且兩數不同，不是錯誤，見第 5 段。
2-2開收銀台、掃碼或選商品、結帳
在哪裡
零售 POS → 收銀檯 /dashboard/modules/pos-retail/pos（店員端「POS 介面 → 零售 → 結帳」版面與算法相同，只是深色、沒有快捷鍵）
版面
最上方掃描列（掃碼框 +「會員」「發票」兩顆鈕）→ 中間購物車常駐 → 下方「選商品」與掛單 / 預購清單 → 最下方功能列 8 顆（折扣 / 集點折抵 / 用票券 / 用儲值 / 掛帳（月結）/ 備註 / 掛單 / 預購，會動錢的是土色）→ 右側固定結帳區（總計 → 付款方式 → 收現找零 → 結帳鈕）。
按什麼
  1. 加入商品：掃碼（游標預設在「掃描條碼按 Enter」欄）；沒條碼按「選商品」，商品面板由下往上展開，可搜名稱 / 品牌 / SKU / 條碼，點商品後面板不會自己關，挑完按「收起商品」
  2. 數量：− / + 或點數量格跳數字鍵盤，第一個數字取代原本的數量（目前 2 按 3 就是 3，不是 23）
  3. 快捷鍵（僅後台）：F1 跳搜尋、F8 送出結帳、ESC 面板開著時關面板、關著時清空購物車（會確認）
  4. 會員：按掃描列「會員」開「會員與顧客」視窗，輸入手機按「查會員」，找到會顯示姓名、等級、點數、累計消費（整個品牌合計，不分店）。綁錯人按「換人」，按「完成」關窗
  5. 折扣：功能列「折扣」給整單折扣；點購物車裡的商品名稱可「改單價」或「單品折扣」。兩者原因都必填
  6. 付款：右側 2×2「現金 / 信用卡 / LINE Pay / 匯款」加一條「其他付款方式」。選現金才有收現區：輸入收現即顯示找零，收不夠寫「不足 NT$ x」並翻紅，「+100 / +500 / +1000」累加，「剛好」＝找零 0
  7. 發票：按掃描列「發票」開「發票設定」視窗，類型只有二聯 / 三聯 / 捐贈；二聯可再選載具（無載具 / 手機條碼 / 會員載具）。切換類型時舊欄位會被清掉。若發票參數開了「結帳後跳出發票視窗」，按結帳時會先跳「開立發票」視窗確認
  8. 按「結帳 NT$xxx」（或 F8）
會看到
「結帳成功」對話框（訂單編號與金額）、購物車清空、庫存即時扣減。對話框的「列印收據」送到本店收據出單機，「繼續結帳」接下一位。
沒看到
商品卡變灰點不下去 = 該規格庫存 ≤ 0（店員端）。庫存顯示「—」= 暫時讀不到，不擋，以結帳當下檢查為準。集點折抵鎖住 = 還沒選會員，點數要從某個人身上扣。手機條碼載具格式錯 = 直接擋住結帳（刻意的：不擋的話訂單成立、發票卡草稿，客人走了才發現）。掃碼跳「找不到此條碼商品」= 條碼沒建檔，或該規格已被停用。

2-4庫存管理（零售自己那一本）
在哪裡
零售 POS → 庫存管理 /dashboard/modules/pos-retail/stock，頂端三顆按鈕切分頁
三個分頁
異動明細（預設）列出進貨 / 銷售 / 退貨 / 手動 / 盤點 / 調入 / 調出，正數綠負數紅。進貨單填供應商、備註，逐列加變體、數量與單位成本，按「送出進貨單」即增加庫存。盤點在「實際庫存」填數，「差異」即時算出，按「提交盤點結果」。

最容易搞混的一組名詞：零售「庫存管理 → 進貨單 / 盤點」動的是 A 通路可售帳；ERP「採購單」與「期末估值 → 調整」動的是 B 中央帳。兩個都叫進貨、都叫盤點，但不是同一本帳。示範時不要兩個都演，會把客戶講暈。

示範用現成商品：AQ-FD-001-R 孔雀魚薄片飼料（售 180 / 成本 95）、AQ-CS-001 過濾棉單片（60 / 25）、AQ-FD-005 冷凍紅蟲磚 100g（120 / 60）、AQ-CS-005 撈網中號。分類：器材 / 水質用品 / 飼料 / 耗材 / 造景 / 飲料 / E2E test。

  2. 客人說「我有點數要折」，收銀員發現折抵欄鎖住，第一件要做的事是什麼？
  3. 零售「庫存管理 → 進貨單」和 ERP「採購單 → 收貨」，動到的是同一個數字嗎？

3. ERP：廠商 → 採購單 → 收貨 → 庫存異動 → 盤點 → 估值

「你的後台是正式的，今天建的示範資料會留在你的帳上，之後你自己看報表會被它干擾。我回去幫你開一份乾淨的，照你真實的商品結構設，比現在隨手建的有用。」

05不可答應的事（背起來，一字不改）

09-22：原本的紅線 3 / 4 / 5 已經被程式追過去了，三條全部改寫。那份缺口分析文件比程式碼舊——以畫面為準。照舊版講會把我們講得比實際能力還弱，而且紅線 5 會直接跟側欄上看得到的四張單據打架。

紅線 1　不可宣稱能匯入鼎新 A1 的資料

期初遷移格式是照凌越做的。凌越是凌越資訊的獨立產品，不是鼎新系列。這條同時適用會計、商品、客戶、庫存期初。

客戶問「我現在用鼎新，資料搬得過來嗎？」
「我們做過期初匯入，但我要先看你實際匯得出來的檔案長什麼樣再回答你搬不搬得過來，不然我現在講的都是猜的。你先匯一份商品跟庫存的檔給我，我兩天內告訴你哪些欄位對得起來、哪些要人工補。」

加分點：這個回答比「可以」更讓內行客戶信任，因為做過遷移的人都知道沒有人能不看檔就答。

紅線 2　不可說「以後開電商，資料不用搬」

現況商品資料流是單向的：通路（零售 / 電商）的品項會反向長出 ERP 品項，但 ERP 匯入的品項不會自動出現在電商或零售。

客戶問「我先做門市，以後開網路，商品要重建一次嗎？」
「目前這兩邊的商品主檔還沒有完全統一——門市建的會自動進 ERP，但反過來 ERP 進的不會自動長到網路商城去。實務上不是重打一次，是我們幫你做一次對應，這件事我會排進上線流程，不會讓你自己弄。主檔統一是我們正在做的事，做完之後這個問題就不存在了。」

紅線 3　只剩「小數 / 秤重」不可答應——箱進個出做得到，不要再講成沒有

做得到的：進銷存 → 基本設定 → 單位主檔（箱 / 包 / 瓶清單）＋ 品項設定每列的「單位與換算」。頁面自述：「下單填『3 箱』，系統換算成庫存單位再進帳」「1 箱 = 12 包就填 1 和 12」。仍然做不到的（這才是紅線）：庫存帳以整數計量，換算後不是整數的數量會被擋。1 箱 = 12 包時，0.5 箱＝6 包可以，0.3 箱＝3.6 包不行 ⇒ 論斤秤重、賣 0.5 公斤、活魚論兩，還是做不到。

客戶問「我飼料整箱進、單罐賣」（可以答應）
「這個可以。你在單位主檔把『箱』跟『包』建起來，在品項上填『1 箱 = 12 包』，之後下採購單你填 3 箱，系統自己換成 36 包進帳。庫存帳永遠用你設的庫存單位在記。」
客戶問「我底沙是秤重賣的 / 活魚論兩」（不可以答應）
「秤重那一塊我現在沒有，我不騙你。庫存數量目前是整數，換算之後不是整數的它會直接擋下來——比方 1 箱 12 包，你填 0.3 箱它不讓你過。你如果一定要秤重，我們得先把它排進開發，我可以給你時間表，但我不會今天答應你下個月就有。」

上台前提醒：ugomk 目前 0 筆單位資料，準備清單第 3 項沒做的話，這段有話術沒畫面。

紅線 4　價目表有了——不可答應的只剩「沒驗過的那一塊」

做得到的：進銷存 → 價目表（側欄直接點得到），三個分頁 價目表 / 客戶專屬價 / 商品價格別。取價順序：客戶專屬價 → 客戶價目表 → 商品價格別 → 商品售價，前面命中就停。商品價格別六種：零售價、優惠價、定價一～四；客戶沒指定時用零售價。還不可以拍胸脯的：數量級距價。欄位確實在（兩頁都有「級距」欄、試算會提示「命中級距」），但沒有實機驗過取價結果 ⇒ 沒有自己驗過之前，只講「有這個欄位」，不要保證行為（附錄 A13）。

客戶問「我有大盤價、零售價、老客戶價，可以設嗎？」
「可以。我們有價目表：你可以建好幾張價目表，把客戶掛上去，他開單就帶出他那一張的價；要更細的話還可以針對某一個客戶、某一個商品指定專屬價，那一層是最優先的。至於『買 10 個以上再便宜』這種量的級距，欄位在，但我想先跟你的實際規則對過一次再回答你，不然我現在講的是猜的。」

紅線 5　銷售單據已經有了——只能說「還沒開始用」，不能說「還沒有」

側欄上就看得到 銷貨訂單 / 出貨單 / 銷貨退回 / 銷貨發票 四項，客戶自己就讀得到。銷貨訂單頁完整可用，狀態有草稿 / 已確認 / 部分出貨 / 出貨完成 / 已結案 / 已作廢六種；出貨單、銷貨退回、銷貨發票也都各自有頁。（出貨單頁的文案清理正在進行中，現場不要停在那一頁逐字唸。）分界線是「有沒有人在用」，不是「有沒有做」。

客戶問「我接到訂單要先開銷貨單、出貨再開出貨單」
「這條線已經在系統裡了——銷貨訂單、出貨單、銷貨退回、銷貨發票，側欄你看得到，訂單走草稿、確認、部分出貨、出貨完成、結案這幾個狀態。我要誠實跟你講的是：這幾張單我們還沒有客戶正式在用，所以我不會說它久經考驗。你如果是賣給下游店家、要開銷貨單月結，我建議我們挑一個月先跑一輪真單，我陪著你跑，有問題當場修。這比我今天跟你保證它完美有用。」

絕對不要說的：「ERP 沒有銷貨訂單」「銷售那條線還沒做」——客戶一看側欄就知道你在亂講。

紅線 6　不要拿別人的規模當案例

不要拿 ugomk（測試站 70 品）或 gaulish（餐飲 772 品項，不同分母）當零售規模案例。講競品時要區分鼎新的產品線：A1 的結論不可外推到 SmartERP / Workflow GP / Cosmos。
