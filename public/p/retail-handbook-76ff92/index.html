零售與進銷存操作手冊

這份手冊假設你從來沒有用過任何 POS 或 ERP。每一節都照同一個順序講：這件事在哪裡做、一步一步怎麼做、做完要去哪裡確認它真的成功了、以及新手在這裡最常卡住的地方。照順序讀完，你會有能力自己操作，也有能力在客戶面前解釋每個數字從哪裡來。

學習地圖

    尚未開始
    00

    先搞懂三件事，不然後面每個數字都會看不懂

    絕大多數人學 ERP 卡住，不是因為介面難，是因為沒有分清楚「同一個東西」在系統裡有三個身分。這一節只有觀念，沒有操作，但它決定你後面能不能自己排錯。

    一、商品、品項，是兩件事

    商品

    零售 POS ／ 電商

    「拿去賣」的那個東西。有售價、有圖片、有分類，客人看得到。

    品項

    進銷存 ERP

    「管數量」的那個東西。有成本、有單位、有倉別、有安全庫存，客人看不到。

    同一罐飼料，在收銀台是「商品」，在倉庫是「品項」。兩邊是各自獨立的資料，要靠人把它們對起來。這就是為什麼你會在兩個地方看到很像的清單，卻不是同一張表。

    二、庫存有好幾本帳，不是一本

    零售自己的庫存

    零售 POS → 庫存管理

    收銀台賣掉就扣。它只知道「賣出去幾個」。

    進銷存中央帳

    進銷存 → 進銷存中央帳

    叫貨、收貨、調撥、盤點、損耗都記在這裡。這是「真正的庫存」。

    電商庫存

    電商模組

    網路訂單扣的那一本。

    最常見的誤解

    「我在 ERP 收了 100 罐，為什麼收銀台還是顯示缺貨？」——因為那是兩本帳。要不要共用同一本，是每一家門市各自的設定（門市設定裡的庫存模式）。示範時若沒先講這句，客戶一定會當場抓到你。

    三、單位：你叫貨的單位，和你賣的單位，常常不一樣

    你跟廠商叫「1 箱」，但你賣給客人是「1 包」。系統要知道 1 箱 = 12 包，才能把叫貨的數量換算成庫存的數量。所以有三個單位欄位：

    單位角色用在哪裡例子
    庫存單位帳上永遠用它記數量包
    採購單位開採購單時可以用它填箱（1 箱 = 12 包）
    銷售單位出貨時可以用它填包

    換算完必須是整數

    1 箱 = 12 包時，你填 0.3 箱 會被擋下，因為換算成 3.6 包不是整數，帳上記不了。系統會直接告訴你可以改填什麼（例如 0.25 箱＝3 包）。散裝秤重、論斤賣，目前還做不到——這句話要記住，客戶問起不要答應。

    01

    登入與切換門市

    所有操作之前，先確認一件事：你現在正在操作哪一家店。多門市的系統裡，九成的「奇怪數字」都是因為站錯店。

    1. 用後台網址登入，輸入帳號密碼。
    2. 登入後看側欄上方「當前門市」那一格——那就是你現在所在的店。
    3. 要換店，從「當前門市」下拉選另一家（只有一家店的公司不會出現這一格）。切換後整個後台的數字都會跟著換，包含庫存、訂單、報表。

    做完要確認

    • 畫面上顯示的門市，就是你以為的那一家。
    • 換店之後，隨便開一張訂單列表，筆數應該跟著變。沒變就是沒切到。

    總部與分店看到的東西不一樣

    總部看得到全部門市；分店只看得到自己那一家。這不是權限壞掉，是刻意的。所以「我這裡查不到那張單」的第一個問題永遠是：你在哪一家店？

    02

    零售 POS：把東西賣出去

    零售這條線最短，先學它建立信心。整條路是：

    商品管理→ 收銀檯（結帳）→ 訂單管理→ 退換貨→ 日結

    零售有兩個入口，看到的是同一批訂單：

    入口怎麼進去裡面有什麼
    後台（坐著用）後台側欄的「零售 POS」群組收銀檯 / 商品管理 / 訂單管理 / 退換貨處理 / 庫存管理 / 日結對帳 / 模組設定 / 收銀版面設定 / 收據出單機設定
    店員端 POS（站著用觸控）後台側欄最上方「POS 介面」（另開分頁）；POS 員工登入後直接進入「零售」七項：結帳 / 查價 / 訂單 / 退換貨 / 日結 / 交班 / 銷售報表

    「商品匯入」與「商品分類」已經不在側欄上，入口改在 商品管理 頁右上的「批次匯入」「商品分類」兩顆鈕。

    2-1　建一個商品

    位置側欄›零售 POS›商品管理›新增商品
    1. 按右上「新增商品」，填商品名稱。
    2. 在變體（規格）那一列填售價（賣多少）和成本（進多少）。成本沒填，之後的毛利報表就是空的。
    3. 選分類。分類要先從商品管理右上的「商品分類」建好，這裡才選得到。
    4. 有廠商條碼就填條碼；沒有就按該列的「產生店內條碼」，系統依店家設定的格式自動產一組（預設是 2 開頭的店內碼，不會撞到廠商條碼）。
    5. 按「建立商品」存檔（編輯既有商品時這顆鈕叫「更新商品」）。

    做完要確認

    • 回商品列表找得到它。
    • 開收銀檯掃它的條碼，會進購物車（掃不進去多半是規格被停用、或商品沒上架）。

    規格可以單獨停用、單獨啟用

    一個商品底下有好幾個規格時，編輯頁的變體清單每一列右邊有一顆按鈕：

    • 已經存檔過的規格：按鈕寫「停用」或「啟用」，沒有刪除。停用後收銀台掃不到、也賣不了；庫存數字與歷史訂單都會留著，之後在同一頁按「啟用」就能還原。這個動作會立刻生效，不用再按「更新商品」。
    • 還沒存檔的新列：按鈕寫「刪除這列」，刪掉不會留下任何紀錄。
    • 清單標題會寫「共 N 個，其中 M 個已停用」，每一列也標「上架中」或「已停用」，看得出哪幾個是停用的。

    兩種停用會被擋下

    商品本身已下架時，不能單獨啟用某個規格（啟用了收銀台也看不到，要先把商品上架）；也不能停用一個商品最後一個上架中的規格（要收起整個商品，請改用商品列表的「下架」）。

    商品很多的時候

    不要一筆一筆建。用商品管理右上的「批次匯入」上傳表格，一次幾千筆。匯入前系統會先讓你看「這次會新增幾筆、更新幾筆」，確認了才真的寫進去。

    2-2　收銀結帳

    位置後台側欄›零售 POS›收銀檯·店員端 POS›零售›結帳

    兩個入口的版面與算法一模一樣，差在配色（店員端是深色）與鍵盤快捷鍵（只有後台有 F1 搜尋、F8 結帳、ESC 關商品面板或清空）。畫面分五塊：

    位置是什麼
    最上方掃描列：「掃描條碼按 Enter」掃碼框，旁邊「會員」「發票」兩顆鈕，鈕上直接寫出目前的會員姓名與發票開立方式
    中間購物車：常駐，不會被商品區擋住，每列有列號
    購物車下方「選商品」，以及「掛單清單」「預購清單」兩個入口
    最下方功能列 8 顆：折扣 / 集點折抵 / 用票券 / 用儲值 / 掛帳（月結）/ 備註 / 掛單 / 預購。會動到金額的是土色，不會的是灰色
    右側固定結帳區：總計 → 付款方式 → 收現與找零 → 結帳鈕
    1. 加商品：直接用掃描槍掃，掃完自動進購物車。沒有條碼時按「選商品」，商品面板會由下往上展開（面板頂端可搜尋名稱、品牌、SKU、條碼），點商品就加入；點完面板不會自己關，可以連點好幾樣，挑完按面板上的「收起商品」。
    2. 改數量：按 − / +，或點中間的數量格跳出數字鍵盤。第一個按下的數字會取代原本的數量：目前 2 件、按 3 再按「確定」就是 3 件，不會變成 23。
    3. 綁會員：按掃描列的「會員」，開「會員與顧客」視窗，輸入手機按「查會員」，按「完成」關窗。查到後那顆鈕會改寫會員姓名。沒有會員也能結帳，只是不累積消費與點數。
    4. 打折：功能列「折扣」給整單折扣；點購物車裡的商品名稱可以改單價或單品折扣。兩種都要填原因，會記下是誰給的。
    5. 發票：按掃描列的「發票」開「發票設定」視窗，選二聯（可選無載具 / 手機條碼 / 會員載具）、三聯（填統編）或捐贈（填愛心碼），按「完成」。切換類型時，舊類型的欄位會被清掉，上一位客人的統編不會留在畫面上。
    6. 選付款方式：右側 2×2 四顆「現金 / 信用卡 / LINE Pay / 匯款」，下面另一條「其他付款方式」。
    7. 收現（僅現金）：選現金時才出現收現區，切到信用卡就收起來。點「收現」輸入客人給的錢，「找零」立刻算出來；收不夠時找零寫「不足 NT$ x」，整塊變紅。快捷鈕「+100 / +500 / +1000」是累加，「剛好」＝客人給的剛好等於應收，找零 0。
    8. 結帳：按右側最底下的「結帳 NT$xxx」。若「發票參數」有開「結帳後跳出發票視窗」，這時會先跳出「開立發票」視窗（與餐飲 POS 同一個），把「發票設定」選好的內容帶進來，按「確認」才真的送出、按「取消」什麼都不會送；沒開這個設定就直接送出。
    9. 收據：「結帳成功」對話框按「列印收據」，送到本店的收據出單機（印過之後改寫「再印一張」）；按「繼續結帳」接下一位。

    做完要確認

    • 訂單管理裡出現這一筆，金額正確。
    • 零售的庫存管理裡，那個商品的數量少了。
    • 有綁會員的話，會員的累積消費增加了。

    掛帳不在付款方式裡

    企業客戶月底一起請款時用的「掛帳（月結）」，放在功能列，不在右側付款方式那一區——它回答的不是「客人用什麼付」，而是「這一單先不收錢」。只有啟用會計總帳、並在應收帳款開了「零售 POS 掛帳」的公司才看得到。按了之後右側會出現客戶清單，結帳鈕變成「掛帳 NT$xxx」；改按任一付款方式就取消掛帳。

    付款方式按錯，系統不會提醒你

    零售的付款方式是固定五種，不能自己新增。收銀員若把刷卡的單按成「現金」，結帳照樣成功、不會有任何錯誤訊息，要到日結看「各付款方式」那張表跟機台對不起來才會發現。結帳前看一眼右側哪一顆是亮的。

    2-3　查價（店員端）

    位置店員端 POS›零售›查價

    客人拿著商品問「這個多少錢、還有沒有貨」時用。掃條碼會跳出一張卡片（品名、規格、SKU、條碼、售價、庫存）；也可以在搜尋框打品名或 SKU，每個商品下面列出各規格的庫存與售價。只會搜到上架中的商品。

    • 這一頁不能結帳，沒有購物車，也不會改任何資料。要賣就回「結帳」重掃一次。
    • 庫存數字與收銀台商品卡逐字相同：寫「店倉 N」或「庫存 N」，是這家店結帳時真正會扣的那一本。
    • 刻意不顯示「全通路合計」：別家店、網路商城倉的數量不會加進來。報一個比較大的數字給客人，結帳當下就是賣不出去。
    • 查不到時會說「查無此條碼」，不會印成售價 0、庫存 0；庫存讀不到時顯示「—」並註明「庫存暫時讀不到，不是 0」。

    2-4　退換貨

    位置後台側欄›零售 POS›退換貨處理·店員端 POS›零售›退換貨

    找到原訂單，選要退的品項與數量。退款會把庫存加回來、把會員的累積消費扣回去。如果那張單有用點數折抵，點數也會還回去；如果有送點數，會扣回來——但不會把餘額扣成負數，扣不足時會照實記錄差額。

    店員端的流程：按右上「新增退換貨」→ 輸入訂單編號（PR 開頭）按「查詢」→ 選數量、填原因 → 「建立退換貨單」→ 詳情裡「核准」→「完成退款」。完成後會跳出「退貨完成：請照下列金額退給客人」，照那個金額付，不要照訂單總額付。

    2-5　日結與交班

    位置後台側欄›零售 POS›日結對帳·店員端 POS›零售›日結 / 交班

    日結是一整個營業日關店時跑一次。它把今天的收款按付款方式加總（「實收合計（抽屜口徑）」＝訂單金額 − 儲值金抵用 − 退款 ＋ 換貨補差價），讓你跟抽屜與刷卡機核對。這是發現「有人按錯付款方式」最快的地方。日結只讀資料與列印，按幾次都不會改到數字。

    交班是另一件事：早班換晚班時，當班那個人點自己收的現金、把責任交出去。一個營業日可以有很多班。

    1. 沒有開著的班時，把抽屜裡的「備用金」點一次填進去，按「開班」。同一家店同時只能有一個開著的班。
    2. 班內的現金進出（換零錢、買清潔用品、老闆提領）用「現金收付」選「現金收入」或「現金支出」，填金額與原因，按「記一筆」。
    3. 不結帳也要打開抽屜時，用「開錢箱」填原因再「確認開啟」，每一次都會記下是誰、什麼時候、為什麼。
    4. 下班時把抽屜現金點一次填進「實點現金」，按「結班」再按「確認結班」。系統算出短溢（實點 − 應有），結班後不可以再修改，要更正只能另記一筆現金收付。

    應有現金只算抽屜

    交班的「應有現金」不含刷卡、LINE Pay、儲值金——那些錢根本沒進抽屜。和日結的「實收合計」本來就不會相等。

    03

    ERP 主檔：開始叫貨之前要先設好的東西

    主檔就是「基本資料」。這一段很無聊，但主檔沒設好，後面每一張單都會卡住。順序有意義，照這個順序做。

    這幾頁都收在側欄「進銷存 › 基本設定」裡：點進去是一張卡片清單，再點一次才到目標頁。進到目標頁後，頁面頂端的麵包屑（例如「進銷存 / 基本設定 / 供應商」）會告訴你它掛在哪裡。

    單位主檔→ 品項設定→ 倉庫管理→ 供應商→ 價目表

    3-1　單位主檔

    位置側欄›進銷存›基本設定›單位主檔

    先把你會用到的單位建起來：包、箱、瓶、公斤。每個單位有一個代號和一個名稱。

    代號建立後不能改

    品項記住的是代號不是名稱。名稱可以改（「箱」改成「大箱」沒問題），代號不行。要停用一個單位，系統會先告訴你還有幾個品項在用它，用中的停不掉。

    3-2　品項設定與換算率

    位置側欄›進銷存›基本設定›品項設定
    1. 新增品項，填名稱與編號。
    2. 設庫存單位（帳上用哪個單位記）。
    3. 需要的話設採購單位與換算率：「幾個採購單位 = 幾個庫存單位」。1 箱 = 12 包，就填 1 和 12。
    4. 銷售單位同理。
    5. 填成本。沒有成本，之後所有毛利數字都是零。

    為什麼換算率要填兩個數字

    因為「1 箱 = 12 包」用一個小數表達不了。如果只存 1÷12 ＝ 0.083333，賣 12 包換算回來會變成 0.999996 箱，一筆正常的整箱出貨反而會被擋掉。填兩個數字（12 和 1）就永遠精確。

    3-3　倉庫管理

    位置側欄›進銷存›基本設定›倉庫管理

    庫存是記在「某個倉庫裡有幾個」。至少要有一個倉。有前場後場、有多個門市，就各自建。

    3-4　供應商

    位置側欄›進銷存›基本設定›供應商

    你跟誰叫貨。開採購單時要選它，所以先建。

    3-5　價目表（賣給不同客戶不同價）

    位置側欄›進銷存›價目表›分頁：價目表 / 客戶專屬價 / 商品價格別

    這是批發生意的核心。系統找價格的順序是由細到粗，找到就停，不會自動挑最便宜的：

    順序這一層是什麼什麼時候用
    1客戶專屬價這一個客戶、這一個商品，就是這個價
    2客戶掛的價目表這個客戶屬於「經銷價」這一組
    3商品價格別這個商品的零售價／經銷價／會員價
    4商品本身的售價前面都沒有，就用它

    開單時畫面會告訴你「這個價是從第幾層來的」。客戶問「為什麼不是給我專屬價」，你當場答得出來。

    總部建的價目表，分店拿不到

    這是刻意的。分店取不到價時會明白告訴你「這一層沒有設」，你當場看得見；如果讓它自動去拿總部的價，分店會用一個你不知道的價出貨，要到對帳那天才發現。要讓分店共用，正確做法是把價目表複製一份到那家分店。

    04

    採購線：從缺貨到貨進來

    這是 ERP 最核心的一條線，也是客戶最有感的一段。

    安全庫存→ 採購單→ 收貨→ 庫存增加

    4-1　安全庫存：讓系統提醒你該叫貨了

    位置側欄›進銷存›基本設定›安全庫存

    替品項設一個「低於幾個就該補」的數字。設了之後，補貨建議才有東西可以算。

    4-2　開採購單

    位置側欄›進銷存›採購單
    1. 新增採購單，選供應商與進貨倉庫。
    2. 加明細：選品項、填數量。數量旁邊可以切採購單位（填 3 箱，系統換算成 36 包）。
    3. 填單價，系統算金額。
    4. 存成草稿，或直接送出。

    做完要確認

    • 明細上顯示的換算結果是你要的（3 箱 = 36 包）。
    • 此時庫存還沒有變——下單不等於到貨，這點要跟客戶講清楚。

    4-3　收貨（可以分批）

    1. 貨到了，回到那張採購單，按收貨。
    2. 填實際收到多少。叫 36 包只到 24 包，就填 24，這張單會變成「部分收貨」。
    3. 剩下的 12 包之後再到，再收一次。

    做完要確認

    • 進銷存中央帳的庫存，數量增加了。
    • 庫存異動紀錄多一筆，寫得出是哪張採購單造成的。
    • 採購單的狀態變成部分收貨或已收貨。

    收貨目前只能用庫存單位填

    下單那一端可以切箱，收貨這一端還不行，要用庫存單位（包）填。知道這個邊界，現場才不會當著客戶的面找不到那個下拉選單。

    05

    銷售線：報價、出貨、開發票、退回

    這條線是採購線的鏡子。採購是「單 → 收貨 → 庫存加」，銷售是「單 → 出貨 → 庫存減」。看得出對稱，就不會記錯。

    銷貨訂單→ 出貨單→ 銷貨發票→ 銷貨退回

    5-1　銷貨訂單

    位置側欄›進銷存›銷貨訂單

    客戶下單，還沒出貨。選客戶、加品項、填數量，價格會依前面那個四層順序自動帶出來。此時庫存不動。

    5-2　出貨單

    位置側欄›進銷存›出貨單

    從銷貨訂單產生出貨單，可以分批出。過帳的那一刻庫存才真的扣。

    做完要確認

    • 庫存減少的數量，等於這次出貨的數量。
    • 原訂單的狀態變成部分出貨或已出貨。
    • 出貨明細的單價是從訂單抄下來的，不會重新算一次價——所以中途改價目表不影響已開的單。

    5-3　銷貨發票

    位置側欄›進銷存›銷貨發票

    出貨之後開發票。一張發票可以涵蓋多張出貨單，但不能混不同分店（賣方統編是各分店自己設的）。

    5-4　銷貨退回

    位置側欄›進銷存›銷貨退回

    出貨的反面：貨退回來、庫存加回去。退回單是從出貨單產生的，所以退不回你沒出過的東西，也退不超過出貨量。

    06

    盤點、批號、組合品、損耗

    6-1　盤點

    實際去數，跟帳上比對，差多少就調整。盤點是唯一合法的「讓帳跟實際一致」的手段——不要直接改庫存數字，那樣就查不出東西少去哪了。

    6-2　批號效期

    位置側欄›進銷存›批號效期

    食品、飼料、藥品要追批號。設了之後，收貨要填批號與效期，出貨要指定出哪一批。追批號的品項，沒填批號會直接被擋下，不會讓你含糊帶過。

    6-3　組合品 BOM 與組裝

    位置側欄›進銷存›基本設定›組合品 / BOM·側欄›進銷存›組裝入庫 / 拆裝

    「禮盒 = 3 罐飼料 + 1 個盒子」這種。先在 BOM 設定成分，再用組裝入庫把成分變成成品（成分減少、成品增加），拆裝就是反過來。

    6-4　損耗率報表

    位置側欄›進銷存›報表與結帳›損耗率報表

    破損、過期、試吃的比例。生鮮與食品客戶對這一頁最有感——它直接是錢。

    07

    報表與對帳：確認數字沒有跑掉

    位置側欄›進銷存›報表與結帳
    這一頁回答什麼問題
    進銷存報表現在每個品項還有幾個、在哪個倉
    銷售報表賣了多少錢、賺多少毛利（要有成本才算得出來）
    三方對帳零售賣出、ERP 扣帳、發票開立，三邊對不對得起來
    期末結帳把一個月封起來，之後不能再偷改那個月的數字

    毛利是 0 通常不是 bug

    是商品沒填成本。系統只能用你給它的成本算毛利，沒給就是 0。示範前先確認有幾個商品有成本，不然打開銷售報表會很尷尬。

    08

    卡住的時候，照這個順序查

    症狀先查這個為什麼
    查不到那張單你在哪一家店分店只看得到自己的單
    ERP 收了貨，收銀台還是缺貨那家店的庫存模式兩本帳，沒設共用就不會同步
    數量填不進去、被擋下換算後是不是整數0.3 箱 = 3.6 包，帳上記不了
    毛利是 0商品有沒有填成本沒成本就算不出毛利
    現金對不起來日結「各付款方式」那張表收銀時按錯付款方式不會報錯，只有在這裡對得出來
    分店取不到價價目表建在誰底下總部的價分店拿不到，要複製過去
    側欄找不到某一頁模組有沒有開通；進銷存的主檔與報表在「基本設定」「報表與結帳」裡付費模組沒開就不顯示；供應商、倉庫管理、進銷存報表這些頁不在側欄上，要先點這兩個導覽頁
    掃碼進不了購物車（跳「找不到此條碼的商品」或「找不到此條碼商品」）那個規格是不是被停用了停用的規格收銀台掃不到也賣不了；到商品管理編輯頁看該列是不是「已停用」，按「啟用」即可
    凌晨看銷售報表，日期寫昨天、筆數跟訂單或日結對不起來營業日 vs 日曆日店員端「銷售報表」用營業日（預設凌晨 05:00 換日，之前的交易算前一天，畫面會標「營業日口徑」）；「訂單」與「日結」用日曆日。換日點可在 餐飲 POS › 商家設定 › 營業日換日 或 美業預約 › 預約參數 › 營業日換日時間 調整；只開零售的公司目前沒有這個入口，請聯繫客服

    萬用心法

    • 先問「這個數字是哪一本帳的」，再問它對不對。
    • 每做完一步就去下游確認一次，不要連做五步才發現第一步就錯了。
    • 系統擋你的時候，它通常會說要怎麼改。把那句話讀完再動作。
